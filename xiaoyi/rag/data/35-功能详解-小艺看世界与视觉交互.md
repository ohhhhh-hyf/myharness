# 小艺看世界与视觉交互

> "小艺看世界"是小艺的**视觉入口**：把摄像头看到的东西转成自然语言交互——
> 它既服务视障用户，也是智慧屏等大屏设备上"用眼睛指挥"的基础能力。

## 一、能力定位

| 维度 | 说明 |
| --- | --- |
| 技术底座 | **多模态大模型** + 视觉识别 + 实时语音交互 |
| 交互方式 | 自然地与小艺实时交流，了解眼前环境、物品等信息 |
| 承载设备 | 华为 AI 眼镜、手机、智慧屏（MateTV）等 |
| 首次亮相 | 2024 中国国际福祉博览会（此后 2025、2026 连续展出） |

## 二、两项关键交互能力

**1. 指向问答**

不必描述清楚"哪个东西"，可以直接**指向目标**提问。系统把"指向 + 问题"组合理解为一次查询，
回答的是**你指的那个**对象，而不是泛泛而谈。

**2. 主动预警（HarmonyOS 6 起）**

- 可识别**障碍物并主动播报方位和距离**；
- 区别于"问了才答"：预警是**不需要用户发起**的主动播报。

> 这两项能力对无障碍场景意义最大：指向问答降低了"描述障碍"的门槛，
> 主动预警则补上了"没意识到要问"的盲区。

## 三、无障碍场景（视障辅助）

详见《小艺无障碍能力详解》，此处只列与视觉交互直接相关的部分：

| 能力 | 作用 |
| --- | --- |
| 环境描述 | 了解眼前的场景、物品 |
| 指向问答 | 询问具体目标（不必先描述） |
| 障碍物预警 | 主动播报方位与距离 |
| 实时对话 | 自然语言连续交流，而非"一次识别一次播报" |

**生态意义**：华为在 2026 中国国际福祉博览会展示了"全场景多终端无障碍普惠方案"，
小艺看世界是其中的核心组成。

## 四、智慧屏上的视觉交互

智慧屏 MateTV 搭载了小艺 Claw 与"小艺看世界"视觉交互，把视觉能力从"随身设备"扩展到"客厅大屏"：

- 大屏有更好的**观看与展示条件**（描述结果可以可视化呈现）；
- 结合摄像头可做**家庭场景**的视觉理解；
- 与全屋智能联动（见《智能家居与车家互联》）。

## 五、与其他视觉能力的关系

小艺的"视觉"分散在多个入口，容易混淆：

| 入口 | 做什么 | 说明 |
| --- | --- | --- |
| **小艺看世界** | 理解眼前环境并对话 | 实时、对话式、面向环境理解 |
| **智慧视觉 / 识屏** | 识别屏幕内容 | 面向"屏幕上的字与物" |
| **小艺修图** | 修图与影像创作 | 面向已有照片（见《小艺修图与影像创作》） |
| **拍照解题** | 识别题目并讲解 | 面向学习场景（见《小艺办公与学习场景实操》） |

> 简单区分：**看世界管"眼前的现实"，识屏管"屏幕上的内容"，修图管"已经拍好的照片"。**

## 六、使用前提与边界

**前提：**

1. 需要支持多模态输入的机型（部分能力依赖 AI 眼镜等配件）；
2. 摄像头权限与相关服务开关；
3. 联网（多模态大模型推理通常需要云侧算力）。

**边界：**

- 复杂视觉推理**依赖网络与云侧模型**，弱网下体验下降；
- 主动预警属于**辅助提示**，不能替代盲杖、导盲犬等专业辅具，安全场景请勿单独依赖；
- 识别结果受光照、遮挡、角度影响，**重要信息建议二次确认**；
- 具体可用机型与版本以官网支持页为准。

## 七、常见问题

| 问题 | 解答 |
| --- | --- |
| 小艺看世界和识屏有什么区别？ | 看世界理解**现实环境**并对话；识屏识别**屏幕上的内容** |
| 必须戴 AI 眼镜吗？ | 手机也可用；AI 眼镜是更自然的免手持形态 |
| 视障用户能免费用吗？ | 该能力在无障碍场景长期作为普惠方案展出，具体开通方式与机型以官方说明为准 |
| 主动预警能替代导盲设备吗？ | 不能。它是辅助提示，安全场景不应单独依赖 |
| 哪些设备支持？ | 手机、华为 AI 眼镜、智慧屏 MateTV 等，随版本推进扩展 |
