# 盘古大模型接入与智慧助手升级（2023-2024）

> 2023 年盘古大模型接入后，小艺成为首个搭载大模型的终端智慧助手；
> 2024 年随 Harmony Intelligence 发布，小艺升级为**系统级智能体**，具备跨应用任务规划与调度能力。

## 一、2023：盘古大模型接入

| 时间 | 事件 |
| --- | --- |
| 2023-07 | 华为发布**盘古大模型** |
| 2023-08 | 推出基于盘古的小艺助手 |
| 2023-09-01 | 盘古版小艺开启众测推送 |
| 同期 | 随 **HarmonyOS 4** 发布，小艺成为首个搭载大模型的终端智慧助手 |

- 技术基础：依托**盘古 L1 层对话模型**，支持复杂指令识别、文案生成、图片识别等。
- 规模数据（2023-08 华为开发者大会披露）：
  - 手机版小艺**月活用户超 2 亿**（主要为中国大陆）；
  - 智慧屏小艺**日均唤醒 7 次以上**；
  - **87.6%** 的座舱操作由小艺完成。

## 二、2024：Harmony Intelligence 与系统级智能体

**2024 年 6 月 HDC 大会**，华为发布"**鸿蒙原生智能**（Harmony Intelligence）"，小艺全面升级为**系统级智能体**。

### 能力升级要点

- 基于**盘古大模型 5.0**；
- 掌握**万亿级 Tokens** 知识量；
- 支持 **23 类 TOP 场景**，任务成功率达 **90%**；
- **300+ 服务**通过**意图框架**接入小艺。

### 交互方式升级

| 交互能力 | 说明 |
| --- | --- |
| 导航条长按唤醒 | 长按屏幕底部导航条唤起小艺 |
| 全局拖拽处理 | 把图片/文件/文字拖到导航条，交给小艺处理 |
| 跨应用任务规划 | 自动联动日历、联系人、短信等完成复杂任务（如"发短信给某人"全流程） |

### 与 HarmonyOS 深度融合

- 小艺不再只是 App，而是**系统能力的一部分**：可从任意界面唤起、理解当前屏幕内容、调用系统服务；
- "可见即可说"等能力让用户能直接念出屏幕上的按钮/内容名称完成操作。

## 三、从"指令任务式"到"对话思考式"

盘古大模型接入带来的根本变化：

| 维度 | 大模型前 | 大模型后 |
| --- | --- | --- |
| 交互形态 | 单轮指令 | 多轮连续对话 |
| 指令理解 | 模板匹配 | 语义理解 + 复杂指令拆解 |
| 任务执行 | 单点功能 | 跨应用任务链 |
| 内容能力 | 信息查询 | 文案生成、文档摘要、图片理解 |

## 四、这一阶段的历史意义

1. **能力底座换代**：从规则引擎切换到大模型驱动；
2. **系统地位确立**：小艺成为系统级入口，为 2025 年后的 Agent 化铺路；
3. **生态接口雏形**：意图框架 + 服务接入，成为后来鸿蒙智能体框架（HMAF）与智能体广场的前身。
