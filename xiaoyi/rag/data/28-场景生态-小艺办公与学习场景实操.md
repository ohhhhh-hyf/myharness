# 小艺办公与学习场景实操

> 从"问一句答一句"到"把活干完"：小艺在办公与学习场景提供端到端能力——
> 端侧 Agent 做文件与日报、对话式文档编辑改稿、闪卡与研究报告助学习。

## 一、办公场景

### 1. 小艺任务（HarmonyOS 7 端侧 Agent）

| 任务 | 说明 |
| --- | --- |
| 文件智能归类 | 按语义把合同、简历、项目资料等整理到合适位置 |
| 批量重命名 | 内容感知命名（如读取合同甲方、日期、金额） |
| 重复文件清理 | 清理重复项，并支持**语义回滚**（说"撤销刚才的文件整理"即可回退） |
| 日报 / 周报 | 自动读取数据源、匹配排版，一键生成规范格式 |
| 智能填表 | AI 操作浏览器、以表填表、网申录入 |

**能力底座**：可调用 2100+ 项系统能力、2000+ 个鸿蒙智能体、500+ 伙伴精选 Skill；
复杂任务成功率超 90%（HMAF 2.0）。端侧运行，更安全、更稳定。

### 2. 对话式文档编辑（Mate XT2 大屏）

- 官方定位：端侧厂商首个**全维度指令集覆盖**的文档编辑引擎；
- 交互：**语音指令**或**手写笔划词**，意图级精准编辑，一次指令完成全篇联动优化；
- 示例："投标人 C 的运维服务费增加 25%，并且把这个表做成一个柱状图"。

### 3. 跨端办公

- **休眠态跨端办公**：手机小艺远程调取休眠/合盖 PC 中的文件，支持翻译、摘要、思维导图并回传手机；
- 文档助理可与 **WPS Office、亿图脑图 MindMaster** 协同（鸿蒙电脑）。

## 二、学习场景

| 能力 | 说明 |
| --- | --- |
| 课件生成 | 根据文档或网页链接生成教学课件（标准课堂/情境探究模式） |
| 教案生成 | 上传教材生成教案，可选课时 |
| 知识闪卡 | 鸿蒙电脑端：基于科学记忆法把学习资料做成填空、选择、问答闪卡 |
| 小艺深度研究 | 跨格式解析文本、图像与 PDF，输出**带引用的结构化研究报告** |
| 小艺深度解题 | 拍照解题、批改作业、收录错题 |

## 三、典型一天（示例工作流）

```text
09:00  让它整理昨天导出的合同 → 自动归类 + 重命名
10:30  开会 → "开启小艺慧记"（实时转写、待办提取）
12:00  会后就地提问 → "前面讲了什么" + 导出 Word
14:00  改方案 → 对话式文档编辑："把第三章重写得更简洁，并加一张对比表"
17:30  写周报 → "生成这周周报"（端侧 Agent 读取数据源排版）
20:00  学习 → 生成知识闪卡，错题收录
```

## 四、效率建议

1. **先说目标，不写步骤**：如"把这批合同按甲方分类"，而不是逐条指令；
2. **善用回滚**：文件整理类任务做完先核对，不满意直接说"撤销刚才的文件整理"；
3. **会议前准备**：导入参会人名单可显著提升慧记发言人识别；
4. **资料喂给"深度研究"**：多文档 + 需要引用的场合优先用它；
5. **隐私敏感资料**：走本地 AI / 端侧能力，或切基本模式。

## 五、常见问题

| 问题 | 解答 |
| --- | --- |
| 小艺任务需要什么版本？ | HarmonyOS 7 起（端侧 Agent 能力） |
| 对话式文档编辑所有机型都有吗？ | 目前为 Mate XT2 大屏专属体验 |
| 闪卡只能在鸿蒙电脑上生成吗？ | 是的（知识闪卡为鸿蒙电脑端能力） |
| 生成的内容能直接用吗？ | 建议人工复核，尤其合同、报表类内容 |
| 办公能力要联网吗？ | 部分能力端侧可完成（如文件整理）；云侧能力需联网 |
