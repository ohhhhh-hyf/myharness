# 智能家居与车家互联

> 在家庭场景里，小艺以"小艺管家"的形态成为**空间智能体**：
> 理解设备方位、支持一句话创建场景、在嘈杂环境中依然可靠唤醒，并与车机实现车家互联。

## 一、小艺管家 6.0：从语音助手到"空间智能体"

**发布**：2026 年 3 月鸿蒙智家技术沟通会发布，AWE2026 展出，2026 年 4 月起分批推送。

### 核心能力

| 能力 | 说明 |
| --- | --- |
| **3D 方位控灯** | 理解家庭设备布局，支持"打开沙发左边的灯""除了书桌上的灯其他都关掉"等**空间指代**指令 |
| **场景大师** | 一句话创建/修改复杂联动场景，如"创建早起场景，每天早上 7 点打开卧室窗帘、播放舒缓音乐" |
| **深度语义理解** | 听懂模糊表达、口误、连续说、改口及"排除式"指令 |
| **悄悄话模式 + 定向降噪** | 深夜可用气声交流；**70 分贝**嘈杂环境下也能精准唤醒 |
| **声纹识别** | 区分家庭成员，孩子声音可触发**儿童专属模式** |
| **安全能力** | 新增紧急求助、**房间锁**（分房间管控） |

## 二、全屋智能的控制方式

### 1. 中控屏（S2、MINI 等）

- 一键执行场景卡片：**回家、离家、观影、睡眠**等；
- 覆盖照明、遮阳、冷暖新风、影音、家电、家具家私等**十大子系统**。

### 2. 语音控制

- 唤醒"小艺管家"直接发指令；
- 示例：说"我出门了" → 执行离家模式（关灯、关空调、关窗帘、启动安防）。

### 3. 场景示例

| 场景 | 联动内容 |
| --- | --- |
| 睡眠模式 | 自动闭帘、助眠微光、音乐、26°C、香薰联动 |
| 健康空气 | CO₂ 过高自动开窗 + 新风；AI 新风托管、风避人吹 |
| 厨房联动 | 开油烟机自动开窗通风 |
| 洗护联动 | 洗衣结束提醒开烘干机 |

## 四、车家互联

- **车机查看家门摄像头**；
- **归家途中提前开启空调/新风**；
- 车载小艺与家庭设备通过鸿蒙分布式能力打通（详见《车载小艺与腕上小艺》）。

## 五、跨设备协同在家庭场景的体现

- 多设备协同唤醒：有屏音箱 > 无屏音箱 > 智慧屏 > 车机 > 手机 > 平板 > 手表（默认排序）；
- 焦点设备优先（手表/耳机/亮屏手机）；
- 服务可在设备间流转（如车载抓拍 → 智慧屏查看）。
