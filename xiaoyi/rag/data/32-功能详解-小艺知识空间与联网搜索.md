# 小艺知识空间与联网搜索

> 小艺的"知识"来自三个不同的地方：**你本机的文档**（知识空间）、**你收藏的资料**（知识库）、
> **互联网**（联网搜索）。三者可以组合使用，而"用哪个"直接决定了隐私边界与回答时效。

## 一、三条知识来源对照

| 来源 | 数据在哪 | 是否联网 | 典型用途 |
| --- | --- | --- | --- |
| **知识空间** | 本机全盘文档 | 可不联网（本地大模型） | 全盘找文件、跨文档总结、年报 / 纪要问答 |
| **知识库** | 你主动收藏的内容 | 问答时可联网融合 | 基于专属资料的个性化问答、AI 播客 |
| **联网搜索** | 互联网 | 必须联网 | 最新信息、时效性查询、附参考来源 |

## 二、小艺知识空间（鸿蒙电脑）

**能力定位**：通过**本地大模型**深度理解用户问题，直接针对本机全盘文档给出答案与总结。

**关键特性**：

- **无需上传文档、无需联网**，隐私数据不出设备；
- 可**切换云端大模型解答（需联网）**，官方口径为"时延更短、效果更佳"；
- 支持**深度思考模式**，适用于逻辑推理类问题；
- 覆盖日常生活、办公（会议纪要、年报、策划文档）、学习考试等场景；
- 支持**跨文档提取信息并总结计算**（不只是检索，而是跨文件归纳）。

**版本门槛**：适用 HUAWEI MateBook Fold / MateBook Pro，HarmonyOS 5.0.1.310 及以上。

> 与"知识库"的区别：知识空间面向**本机已有文件**（你不需要先收藏），
> 知识库面向**你主动收藏的资料**（跨设备、跨来源）。

## 三、小艺知识库

**首发**：Mate XTs 非凡大师（鸿蒙 5.1+）。

| 维度 | 说明 |
| --- | --- |
| 支持内容类型 | 网页、文档、图片、音视频等 |
| 核心能力 | 收藏与管理，并**基于收藏知识进行 AI 问答** |
| 特色输出 | 可生成 **AI 播客** |
| 融合升级 | 鸿蒙电脑 HarmonyOS 6 上，知识库融合本地文档、图片、收藏与在线内容 |

官方对其体验的描述是："无论问单个文件还是整个知识库，都能基于专属资料与网络知识给出更准回答"——
即**本地资料与网络知识可以混合作答**。

## 四、联网搜索

| 时间 | 进展 |
| --- | --- |
| 2025-02 | 小艺 App 升级，**DeepSeek-R1 智能体支持联网搜索**，开启后可获取最新信息并给出参考来源链接 |
| HarmonyOS 6.0.0.328 花粉 Beta | 小艺对话**接入联网分析**，信息来源更丰富；联网搜索结果页支持**多标签切换**与**一键全屏展开** |

**使用要点**：

- 联网搜索是**可开关**的（部分入口需在对话中手动开启），关闭时回答仅基于模型知识；
- 开启后回答会附**参考来源链接**，便于自行核验；
- 时效性问题（价格、新闻、政策、版本号）**务必开联网**，否则容易得到过时答案。

## 五、小艺深度研究

面向需要"多来源整合"的重任务：

- 具备**深度搜索与分析推理**能力；
- 可整合**全网权威信息与本地资料**；
- 自动生成**研究报告**（而非片段式回答）。

这与"问一句答一句"的对话形态不同，适合做调研、竞品分析、资料综述类工作。

## 六、怎么选：一张判断表

| 你的问题 | 建议路径 | 原因 |
| --- | --- | --- |
| "我去年那份年报里营收是多少" | 知识空间（本地） | 答案在本机文件里，无需联网、不泄露 |
| "帮我总结我收藏的这几篇文章" | 知识库 | 基于专属资料作答 |
| "今天有什么新闻 / 最新版本号是多少" | 联网搜索 | 时效性要求高，必须联网 |
| "帮我调研一下某个行业" | 深度研究 | 需要整合多来源并成文 |
| 敏感资料（合同、体检报告） | 知识空间，并关闭云端切换 | 保证数据不出设备 |

## 七、常见问题

| 问题 | 解答 |
| --- | --- |
| 知识空间会把我的文档上传吗？ | 本地大模型模式下**不上传、不联网**；手动切到云端模型时才会联网 |
| 知识空间和知识库什么区别？ | 知识空间是**本机全盘文件**检索；知识库是你**主动收藏**的资料集合 |
| 回答没有来源链接？ | 未开启联网搜索，或该问题走了离线路径 |
| 能在手机上用知识空间吗？ | 知识空间首发于**鸿蒙电脑**；手机端对应的是知识库与联网搜索 |
| 回答不准怎么办？ | 时效性问题开联网；本机问题确认文件是否在检索范围内 |
