# 小艺语音指令速查手册

> 按场景分类的指令速查表。约定：所有指令先唤醒"**小艺小艺**"，再说出下表内容；
> 具体可用性随系统版本与机型略有差异。

## 一、系统控制类

| 说什么 | 做什么 |
| --- | --- |
| 打开/关闭蓝牙 / WLAN / 移动数据 / 热点 / 飞行模式 | 开关对应功能 |
| 打开护眼模式 / 深色模式 / 省电模式 / 静音模式 | 切换系统模式 |
| 把亮度调到最低 / 音量调到 50% | 调节亮度与音量 |
| 关闭所有应用 / 清理后台 | 释放运存 |
| 你在哪里 | 手机最大音量响铃 + 闪光灯闪烁（找手机） |
| 无线投屏 / 截取长截图 / 朗读屏幕文字 | 投屏、滚动截长图、语音播报屏幕文字 |

**官方设置路径参考**：设置 > 小艺 > 唤醒与对话（语音唤醒、连续对话、锁屏语音技能）。

## 七、个性化设置速查（官方路径）

| 设置项 | 路径 |
| --- | --- |
| 语音唤醒 / 自定义唤醒词 | 设置 > 小艺 > 唤醒与对话 > 语音唤醒 |
| 连续对话 | 设置 > 小艺 > 唤醒与对话 |
| 音色（女声/少女/男声/童声/自定义） | 设置 > 小艺 > 音色 |
| 小艺私语（安静场所轻声唤醒） | 设置 > 小艺 > 唤醒（与对话）> 小艺私语 |
| 锁屏语音技能 | 设置 > 小艺 > 唤醒与对话 > 锁屏语音技能 |
| 方言自由说 | 无需手动设置，自动识别（支持方言播报与否因版本而异） |
| 应用服务模式（基本/全量） | 小艺 App >「我的」> 设置 > 应用服务模式 |

## 八、常见问题

| 问题 | 解答 |
| --- | --- |
| 为什么某条指令没反应？ | 老口令可能已下线；系统版本/机型差异也会影响 |
| 方言能用吗？ | 支持约 10 种方言识别（部分机型支持方言播报），混合方言识别率下降 |
| 锁屏能用吗？ | 可在设置中开启"锁屏语音技能" |
| 安静场合怎么用？ | 用小艺私语（靠近麦克风轻声说话） |
