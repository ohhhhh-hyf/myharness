# 小艺 Claw 深度解析

> 小艺 Claw 是小艺体系里**最接近"个人 Agent"**的产品形态：有独立人格、能长期记忆你的偏好、
> 完成复杂任务后会沉淀技能，还支持订阅制付费。它与"主对话里的小艺"不是同一个入口。

## 一、它是什么

| 维度 | 说明 |
| --- | --- |
| 代号 | "龙虾" |
| 技术来源 | 基于 **OpenClaw**（原名 Clawdbot）开源 AI 智能体框架打造 |
| 覆盖设备 | 手机、平板、PC（**一个账号多端通用**） |
| 系统要求 | HarmonyOS 6 及以上（鸿蒙 5.0 及以上机型已陆续开放） |
| 定位 | 个人 Agent：主动执行、深度记忆、多端协同、系统级安全 |

**与主对话小艺的区别**：主对话小艺是"系统级调度者"，用完即走；小艺 Claw 更像一个
**有记忆、有人格、会成长的助手**，需要订阅且独立计费。

## 二、自进化能力（核心卖点）

2026 年 4 月的更新引入自进化：

1. **偏好学习**：对小艺 Claw 说"记住这种风格""以后都用这种格式"，它会识别并学习你的
   **长期偏好**，减少重复沟通；
2. **技能沉淀**：完成复杂任务后会**沉淀专属技能**，越用越贴合使用习惯；
3. **人格进化**：初始人格可随使用过程进化，不是固定预设。

> 工程视角：这是"记忆 + 技能库"的组合——把一次性对话转化为可复用的**个人资产**。

## 三、四种初始人格与技能库

| 初始人格 | 面向 |
| --- | --- |
| 信息猎手 | 检索、聚合、追踪信息 |
| 知心朋友 | 闲聊、情绪陪伴 |
| 办公搭子 | 文档编辑、写 PPT、自动回复邮件 |
| 创作天才 | 内容创作 |

- 精选 **80+ Agent Skills** 开箱可用；
- 人格与技能可随使用进化；
- 接入同花顺、东方财富、高德、麦当劳等**第三方服务 Skill**。

## 四、典型任务

- 文档编辑、写 PPT；
- 自动回复邮件；
- 跨设备管理日程、备忘录、闹钟；
- 基于手表数据的每日健康报告、运动计划并同步至日历（2026-03 预告特性）。

## 五、安全设计

| 层面 | 说明 |
| --- | --- |
| 系统架构 | 依托鸿蒙**星盾**架构做系统级安全加固 |
| 隔离 | **独立用户沙箱** |
| 加密 | **专属密钥**加密 |
| 权威认证 | 2026-04 通过**中国信通院**安全能力评估，成为**首个获国家级智库认证的终端厂商 Claw 类智能体** |

> 对本类产品的关键风险是"Agent 有执行权"：沙箱与密钥隔离的意义在于
> 即使 Agent 被诱导执行越权操作，也**难以触达沙箱外的用户数据**。

## 六、订阅与计费

| 套餐 | 价格 | 点数 |
| --- | --- | --- |
| 体验包 | 49 元 / 月 | 1000 点数 |
| 标准包 | 199 元 / 月 | 6000 点数 |

- 支持**花币**付款；
- 新用户有 **7 天 0 元体验**。

## 七、HarmonyOS 7 中的架构位置

在 HarmonyOS 7 中，小艺基于 **Agentic 自演进架构**，底层分为四层：

| 层 | 职责 | 规模 |
| --- | --- | --- |
| 规划层 | 任务拆解与规划 | — |
| 工具层 | 可调用的系统能力 | **2100+** 项鸿蒙系统能力 |
| 记忆层 | 系统级用户数据 | **200+** 项 |
| 执行框架 | 实际执行与回滚 | — |

由此实现两个转变：从"被动应答"到"**主动执行**"，从"单次对话"到"**深度记忆进化**"。

## 八、使用建议与边界

**建议：**

1. 先用 7 天免费体验评估**点数消耗速度**，再决定是否订阅（不同任务耗点数差异大）；
2. 需要长期偏好时，明确说"记住……"，不要指望它自动领会一次性的口头偏好；
3. 涉及敏感数据前，确认当前任务是否真的需要 Claw 的**执行权限**。

**边界：**

- 属**订阅制付费**产品，与主对话小艺的免费能力是两套体系；
- 有**系统版本门槛**，且需要较高端机型支持端侧 Agent；
- 点数计费方式决定了**长任务成本更高**，重度使用前先估算；
- 健康报告、运动计划同步等能力依赖**华为手表 / 手环**采集数据。

## 九、常见问题

| 问题 | 解答 |
| --- | --- |
| 小艺 Claw 和主对话小艺是同一个吗？ | 不是同一入口。Claw 是独立的个人 Agent 产品，需订阅、有独立人格与记忆 |
| 一定要付费吗？ | 有 7 天 0 元体验；长期使用需订阅（49 元 / 199 元两档） |
| 它能记住我说的话吗？ | 能，且是长期偏好级记忆；也可沉淀为可复用技能 |
| 安全吗？ | 系统级沙箱 + 专属密钥加密，并获信通院安全能力评估认证 |
| 会影响手机耗电吗？ | 端侧 Agent 有功耗控制机制，详见《端侧 AI 的硬件门槛与功耗》 |
