# 多模态交互与大模型协同

> 小艺的"聪明"来自三个层面：**多模态的输入输出**（语音、视觉、触屏、拖拽）、
> **多模型的协同调度**（盘古 + DeepSeek 等）、**意图框架驱动的系统级执行**。

## 一、多模态输入

| 模态 | 入口与能力 |
| --- | --- |
| 语音 | 唤醒词、连续对话、小艺私语、方言自由说 |
| 视觉/屏幕 | 智慧视觉、识屏、可见即可说、屏幕可见可问 |
| 图像/文件 | 拖拽到导航条、拍照、图库选图 |
| 触屏/手写笔 | 长按导航条、划词编辑（HarmonyOS 7 对话式文档编辑） |
| 眼动/穿戴 | 手表翻腕、耳机 AI 键（部分功能） |

**典型多模态动作**：

- 把图片/文件/文字**拖到屏幕底部导航条**，可提取表格、文字、生成摘要；
- 屏幕上有地址 → 说"导航到这"；有电话 → 说"拨打这个号码"；
- 拍照 → 交给小艺解题、翻译、识别、修图。

## 二、多模态输出

- 文字答案 + 语音播报；
- **生成式 A2UI**（2026 平台能力）：由模型动态生成适配界面的交互卡片；
- 音频内容：小艺帮记可把记录生成 **AI 播客**；
- 可视化产物：思维导图、PPT、表格、图表。

## 三、多模型协同调度

### 模型矩阵

| 模型 | 角色 |
| --- | --- |
| 盘古大模型（含盘古 5.0、openPangu 2.0 开源版） | 系统底座与端云协同基础能力 |
| DeepSeek（R1 至 V4） | 深度思考、代码、数学与逻辑推理 |
| 端侧模型（含 HarmonyOS 7 的 30B MoE） | 离线/隐私敏感场景：无网整理相册、端侧任务 |

### 协同机制

- **"万能插座"式接入架构**：可对接盘古、DeepSeek 等业界优质大模型，按任务类型选择；
- **端云协同**：
  - 云侧负责复杂推理与大规模知识（数据即用即删，详见安全文档）；
  - 端侧负责隐私敏感与低时延任务（如唤醒、图像处理、离线任务）；
- **快慢自适应**（HDC 2026 双循环架构）：简单任务走快通道，复杂任务走慢思考。

### 能力效果

在盘古与 DeepSeek 协同赋能下，小艺从"指令任务式"升级为"对话思考式"：

- 推理思考更深度（DeepSeek 展示完整思考过程）；
- 意图理解更精准；
- 语音畅聊更智能；
- 内容创作更优质。

## 四、意图框架与系统级执行

- **意图框架**：300+ 服务通过意图框架接入（HDC 2024 数据）；2025-2026 升级为"**意图即服务**"范式；
- **系统能力调用**：2100+ 系统能力完成 Skill 化；
- **跨应用调度**：自动联动日历、联系人、短信、地图等完成多步任务；
- **权限模型**：系统级智能体可直接调用部分系统底层权限（端侧 Agent 尤其强调本地运行与可控性）。

## 五、能力对照：什么任务走哪条路

| 任务类型 | 主要路径 |
| --- | --- |
| 系统开关、闹钟、提醒 | 端侧意图识别，低时延本地执行 |
| 知识问答、内容创作 | 云侧大模型（盘古/DeepSeek） |
| 图库整理（无网） | 端侧 30B MoE |
| 通话摘要、语音转写 | 云端混合（需联网） |
| 视觉识别（识屏、修图） | 端侧 + 云侧协同 |

## 六、常见问题

| 问题 | 说明 |
| --- | --- |
| 小艺用的是哪个模型？ | 多模型协同：盘古为底座，DeepSeek 等按场景接入，端侧另有轻量/大参数模型 |
| 断网了还能用吗？ | 部分能力可离线（端侧模型），多数云侧能力需联网 |
| 为什么有的回答"思考"很久？ | 深度思考类任务由推理模型处理，会展示思考过程 |
| 多模态能力需要什么系统版本？ | 拖拽、识屏、修图等能力对 HarmonyOS 版本有要求，详见版本对照文档 |
