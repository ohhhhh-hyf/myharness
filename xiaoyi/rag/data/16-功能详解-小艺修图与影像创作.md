# 小艺修图与影像创作

> 小艺把修图变成"说话就能改图"：多模态连续实时修图、AI 消除、老照片修复、AI 扩图，
> 并可在图库、社交与电商类 App 内直接调用。

## 一、小艺修图智能体（HarmonyOS 6.0+）

**定位**：**多模态连续实时修图**的智能助手；精准改图的同时保留画面其他区域的真实细节，做到"所说即所见，所见即所得"。

### 支持环境

| 项目 | 要求 |
| --- | --- |
| 系统 | HarmonyOS 6.0 及以上（部分功能需 6.1 / 7.0） |
| 小艺 App | 11.3.9.320 及以上 |
| 推送 | 功能分批推送 |

### 三种打开方式

1. **小艺 App 内**：发现/广场 → 搜索"小艺修图" → 上传图片 → 输入修图指令（如"帮我增加一个墨镜和项链"）；
2. **图片详情页**：上传图片后直接输入指令；或点击 **AI 消除** 按钮，先涂抹选区再点"消除"；
3. **外部应用唤醒**：图库中选中图片 → 长按桌面底部导航条唤醒小艺 → 输入"消除路人"等指令，小艺自动提取图片与指令生成结果。

### 支持的应用场景

图库、抖音、快手、百度、小红书、知乎、淘宝、京东、B 站、今日头条、大众点评、携程等 App 内均可操作。

## 二、AI 消除（图库内置 AI 修图大师）

- **首发**：华为 Pura70 系列，基于**盘古大模型**能力；
- **原理**：一键消除画面杂物，并通过 **AIGC 生成式填充**补全背景，边缘融合度更优；
- **路径**：图库 → 编辑 → AI 修图 → 消除；
- **两种模式**：
  - **智选模式**（默认）：在消除对象内部画一条线，系统自动识别并扩散选中对象；
  - **手动模式**：涂抹哪里选中哪里，支持调整画笔大小精细调整。

## 三、其他修图能力与技巧

| 能力 | 用法 |
| --- | --- |
| 语音修图 | 打开照片后唤醒小艺，直接口述指令（如"消除照片里背景多余路人"），全程无需触屏 |
| 人像精修 | 图库 → 编辑 → AI 修图 → 人像精修，可调节光影与虚化 |
| 老照片修复 | 通过小艺修图智能体指令完成 |
| AI 扩图 | 扩展画面边缘，补齐构图 |
| 消除路人 | 涂抹 → 一键消除；建议"另存为"而非覆盖原图 |

## 四、版本门槛与限制

| 项目 | 说明 |
| --- | --- |
| 系统版本 | AI 消除、魔法移图等进阶功能需 HarmonyOS 6 及以上；鸿蒙 5.1 仅支持简单人像美颜 |
| 生成速度 | 受网络、图片大小、指令复杂度影响 |
| 次数限制 | 云侧算力有**每日使用次数限制** |
| 编辑范围 | 暂**不支持**身材编辑及五官编辑 |
| 合规 | 会对不符合法规政策的图片或指令做**拦截检测** |
| 权限 | 语音修图无反应时，检查设置 → 智慧助手 → 小艺 → 识屏权限中是否开启图库/相册权限 |

## 五、适用场景

- **旅游照去路人**：AI 消除 + 生成式填充；
- **电商/社交配图**：一句话增删元素（墨镜、项链等）；
- **家庭老照片**：修复清晰度与损伤；
- **构图调整**：AI 扩图改变画幅比例。

## 六、常见问题

| 问题 | 解答 |
| --- | --- |
| 为什么修图入口找不到？ | 检查系统与小艺 App 版本（6.0+ / 11.3.9.320+），功能分批推送 |
| 语音修图没反应？ | 检查识屏权限与图库权限 |
| 能改五官/身材吗？ | 暂不支持 |
| 修图会联网吗？ | 云侧算力处理，有每日次数限制；端侧部分视觉能力在本地完成（见安全文档） |
