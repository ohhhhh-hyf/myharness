# 各版本 HarmonyOS 小艺特性对照

> 小艺与鸿蒙系统深度绑定，很多能力有明确的版本门槛。本文按系统版本整理关键特性与设置路径差异，
> 便于判断"我的设备能不能用某个功能"。

## 一、版本与特性对照总表

| 系统版本 | 小艺关键特性 |
| --- | --- |
| EMUI 9 / 10（2018-2019） | 语音助手 → 智慧助手；连续对话、识屏翻译 |
| HarmonyOS 4（2023） | 盘古大模型接入；复杂指令、文案生成、图片识别 |
| HarmonyOS NEXT / 5.0（2024-2025） | Harmony Intelligence 系统级智能体；小艺通话、小艺字幕更名、小艺私语；DeepSeek 智能体接入（5.0.0.130+） |
| HarmonyOS 5.1（2025） | 小艺帮记（需小艺 App 11.5.2.300+）；鸿蒙电脑端能力扩展 |
| HarmonyOS 6.0（2025-2026） | 小艺慧记（6.0+）；小艺修图（6.0+，部分需 7.0/6.1）；首批 80+ 应用智能体上架 |
| HarmonyOS 6.1（2026） | 小艺帮记身份验证与同步收藏（热更新）；耳机 AI 键启动小艺帮接/摘要；小艺慧记扩展机型 |
| HarmonyOS 7（2026-09） | 小艺任务端侧 Agent、对话式文档编辑、端侧 30B MoE、休眠态跨端办公、小艺自然聊 |

## 二、设置路径的版本差异（重要）

| 设置项 | HarmonyOS 5 | HarmonyOS 6 |
| --- | --- | --- |
| 语音唤醒 | 设置 > 小艺 > 唤醒 > 语音唤醒 | 设置 > 小艺 > 唤醒与对话 > 语音唤醒 |

- 升级 HarmonyOS 5 前需将**智慧语音升级至 12.1.8.410 及以上**，否则需重新开关并录入唤醒词。

## 三、功能更名与迁移动线

| 旧名称 | 新名称 / 现状 |
| --- | --- |
| AI 字幕（HarmonyOS 4.X 及以下） | **小艺字幕**（HarmonyOS 5 起更名） |
| 小艺记忆 / 小艺知识库 | **小艺帮记**（能力升级合并） |
| — | 控制中心字幕入口：HarmonyOS 5 曾下线，6.0.0.328 SP22 起重新上线 |
| 通话场景字幕 | HarmonyOS 5 中下线 |

## 四、能力门槛速查（按功能）

| 功能 | 最低要求 |
| --- | --- |
| DeepSeek 智能体 | HarmonyOS 5.0.0.130+，小艺 App 11.2.10.340+（HarmonyOS 4.x 及以下不支持） |
| 小艺帮记 | HarmonyOS 5.1+，小艺 App 11.5.2.300+ |
| 小艺慧记 | HarmonyOS 6.0+（2025-05 鸿蒙电脑首发） |
| 小艺修图 | HarmonyOS 6.0+，小艺 App 11.3.9.320+ |
| 小艺 Claw | HarmonyOS 6+ |
| 小艺任务 / 对话式文档编辑 | HarmonyOS 7（文档编辑为 Mate XT2 大屏专属） |
| 小艺私语 | HarmonyOS 5.0+ |
| 耳机 AI 键（帮接/摘要） | HarmonyOS 6.1+ 与指定耳机型号 |

## 五、版本升级建议

1. **优先升级系统与小艺 App**：多数新能力同时依赖两者版本；
2. **升级后检查设置**：部分能力升级后会**恢复默认关闭**（如语音唤醒、连续对话）；
3. **全量模式**：小艺 App → 设置 → 应用服务模式 → 全量模式，解锁跨应用能力；
4. **机型差异**：新功能通常旗舰首发、逐步下放，部分功能可能长期不支持某机型。

## 六、常见问题

| 问题 | 解答 |
| --- | --- |
| 为什么同一功能别人有我没有？ | 功能按机型与版本分批推送，受系统版本、小艺 App 版本、机型三重限制 |
| 升级后小艺反而"变笨"了？ | 多数情况是连续对话/后台权限等设置被重置，需手动开启 |
| 找不到某个设置项？ | 设置路径随版本变化（见上表），可用设置内搜索功能定位 |
| 鸿蒙电脑上的小艺和手机一样吗？ | 共享能力底座，但部分能力为 PC 独有（如知识闪卡、本地模型离线问答） |
