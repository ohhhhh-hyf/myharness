# 小艺字幕与多语言翻译

> 小艺字幕负责"把声音变成看得懂的字"，小艺翻译负责"把语言变成听得懂的话"，
> 两者共同覆盖看视频、开会、出国、读外文资料的跨语言场景。

## 一、小艺字幕（原 AI 字幕）

**功能定位**：把手机内的**视频声音**或**麦克风传入的声音**实时转为文字，以**悬浮字幕**形式呈现。

### 开启方式

1. 设置 > 小艺 > 小艺字幕 → 打开开关；
2. 唤醒小艺说"**打开小艺字幕**"（旧系统：AI 字幕）。

### 使用要点

| 项目 | 说明 |
| --- | --- |
| 声音源 | 悬浮窗内可切换「**媒体声音**」（转视频声音）或「**麦克风声音**」（转外部声音） |
| 字幕语言 | 英译中、日译中、韩译中 |
| 双语字幕 | 英/日/韩译中时可显示**双语**（同时显示原文与译文） |
| 悬浮窗操作 | 拖动横条移动、拖边框调整大小、点击关闭 |

### 版本差异（重要）

- HarmonyOS 4.X 及以下叫"**AI 字幕**"，HarmonyOS 5 及以上更名为"**小艺字幕**"；
- HarmonyOS 5 中控制中心快捷入口、桌面快捷方式曾下线，**HarmonyOS 6.0.0.328 SP22 起重新上线控制中心入口**；
- **通话场景字幕在 HarmonyOS 5 中下线**。

## 二、小艺翻译

**入口**：唤醒小艺说出指令，或设置 > 小艺 > 小艺翻译。

### 五种翻译模式

| 模式 | 说明 |
| --- | --- |
| 文本翻译 | 说"打开文本翻译"，输入文字即时翻译 |
| 面对面翻译 | 说"面对面翻译"，点击按钮切换双向模式，双方各按面前的按钮说话，实时显示文字并语音播报 |
| 同声传译 | 说"同声传译/同声翻译"，按界面提示操作 |
| 文档翻译 | 说"打开文档翻译"，按提示操作 |
| 连续翻译 | 浏览外文网站/应用时，长按导航条或电源键唤醒小艺 → 点"连续翻译"，支持网页、应用、文档**边浏览边翻译** |

**语言支持**：官方指令资料显示支持约 **20 种语言**。

## 三、HarmonyOS 7：翻译能力升级

- **Live 态面对面翻译与同传摘要**：双语双向自动切换，翻译准确率提升 **20%+**；
- 与"小艺自然聊"配合，嘈杂环境下也能稳定使用语音翻译。

## 四、实用指令速查

| 想做的事 | 对手机说 |
| --- | --- |
| 开字幕 | "小艺小艺，打开小艺字幕" |
| 面对面翻译 | "小艺小艺，面对面翻译" |
| 同声传译 | "小艺小艺，同声传译" |
| 文档翻译 | "小艺小艺，打开文档翻译" |
| 连续翻译 | "小艺小艺，连续翻译" |
| 翻译句子 | "把这句话翻译成英文：…" |

## 五、适用场景

- **看外文视频/网课**：小艺字幕实时显示中文；
- **跨国会议**：同声传译 + 双语音频输出；
- **出境旅行**：面对面翻译、语音翻译；
- **读外文资料**：文档翻译、连续翻译（网页/应用/文档）。

## 六、常见问题

| 问题 | 解答 |
| --- | --- |
| 字幕为什么没字幕？ | 检查小艺字幕开关、声音源选择（媒体/麦克风）是否正确 |
| 通话时能用字幕吗？ | HarmonyOS 5 起通话场景字幕下线 |
| 支持哪些语言对？ | 字幕为英日韩译中；翻译约 20 种语言 |
| 方言能翻译吗？ | 方言识别能力有限，翻译场景建议使用普通话 |
| 为什么控制中心找不到入口？ | 与系统版本相关（6.0.0.328 SP22 起恢复入口） |
