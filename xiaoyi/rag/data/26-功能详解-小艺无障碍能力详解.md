# 小艺无障碍能力详解

> 小艺的无障碍能力覆盖**视障、听障、语障**三类人群，并被写入华为终端可持续发展报告。
> 本文按人群整理能力、入口与版本要求。

## 一、视障辅助：小艺看世界

### 手机端

| 项目 | 说明 |
| --- | --- |
| 适用版本 | HarmonyOS 5.0 及以上（多款 Mate / Pura / nova 机型） |
| 入口 | 唤醒小艺 → 点击**通话图标** → 打开摄像头；或直接说"**小艺你看**" |
| 使用 | 边走边聊、字幕查看、翻转摄像头、静音、挂断等操作 |
| 场景 | 识别障碍物、红绿灯、文字资料；主动预警（提前播报路况） |

### 华为 AI 眼镜端

| 项目 | 说明 |
| --- | --- |
| 唤醒 | 长按左镜腿 **AI 快捷键**；或语音"进入小艺看世界" |
| 交互 | 手势代指、多轮对话 |
| 场景 | 识别动植物、讲解文物、穿搭建议、翻译餐谱等 |

## 二、语障辅助：小艺声音修复

| 项目 | 说明 |
| --- | --- |
| 定位 | 为发音困难人士智能修复语音，**保留个人音色** |
| 设置路径 | **设置 > 辅助功能 > 声音修复** |
| 使用步骤 | 录制"我的声音"（约 **5 秒**训练）→ 在小艺通话、声音修复应用中使用修复后的声音 |
| 交流方式 | 面对面语音交流（语音球交互）、通话语音交流 |
| 适用版本 | HarmonyOS 6.0 / 6.1 及以上（Mate 80、Pura 90 等机型） |
| 认可 | 入选"2025 年助残科技创新案例"；TECH4ALL 有专题案例报道 |

## 三、听障辅助：听觉与沟通辅助

| 能力 | 说明 |
| --- | --- |
| 小艺通话（文字↔语音双向） | 对方语音转文字显示，自己输入文字转语音传给对方 |
| 通话摘要 | 通话结束自动生成摘要与待办事项 |
| 小艺字幕 | 视频/麦克风声音实时转字幕（中英日韩，可双语） |
| 单声道音频 | 合并声道，适配单耳佩戴 |
| 音量平衡 | 左右耳音量独立调节 |
| 助听设备连接 | 支持连接助听设备（按机型） |
| 声音识别 | 识别环境声音并提醒（按机型） |
| 闪烁提醒 | 来电/提醒以闪光提示 |

## 四、入口与版本速查

| 能力 | 最低版本 | 主要入口 |
| --- | --- | --- |
| 小艺看世界（手机） | HarmonyOS 5.0+ | 唤醒小艺 → 通话图标 / "小艺你看" |
| 小艺看世界（AI 眼镜） | 按眼镜产品要求 | 长按左镜腿 AI 键 |
| 小艺声音修复 | HarmonyOS 6.0/6.1+ | 设置 > 辅助功能 > 声音修复 |
| 听觉辅助项 | HarmonyOS 6.0/6.1+ | 设置 > 辅助功能 > 听觉辅助 |
| 小艺通话 / 通话摘要 | HarmonyOS 5.0+ | 设置 > 小艺 > 小艺通话 |

## 五、常见问题

| 问题 | 解答 |
| --- | --- |
| 小艺看世界必须买 AI 眼镜吗？ | 不是，手机端即可使用；眼镜端提供免手持体验 |
| 声音修复会改变我的音色吗？ | 官方定位是"保留原生音色、提升清晰度" |
| 听障用户怎么打电话？ | 用小艺通话的文字↔语音双向转换，通话后还能自动出摘要 |
| 为什么部分无障碍项找不到？ | 与机型、系统版本相关（多数要求 6.0/6.1+） |
