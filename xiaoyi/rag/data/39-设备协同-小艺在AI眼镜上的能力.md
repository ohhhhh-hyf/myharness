# 小艺在 AI 眼镜上的能力

> AI 眼镜是小艺**唯一"免手持、第一人称视角"**的入口：双手被占用时（骑车、搬东西、做手工）
> 依然能问、能拍、能识别。它把"唤醒 → 看 → 问"压缩成一个按键动作。

## 一、硬件与规格（华为 AI 眼镜）

| 项 | 参数 |
| --- | --- |
| 型号 | AIL-G01 |
| 重量 | **35.5g**（不带衬片） |
| 摄像头 | **1200 万**超感光摄像头 |
| 连接 | 蓝牙 6.0 |
| 续航 | 约 **12 小时**综合续航，磁吸充电 |
| 芯片 | 自研 AI 眼镜芯片 |
| 音频 | 通话智能降噪、AI 轻声交互、自研水滴单元 |
| 售价 | **2499 元起**（4 月 20 日发布，4 月 25 日开售） |

**系统门槛**：小艺看世界需搭配 **HarmonyOS 6.0.0.130 及以上**的部分华为手机。

## 二、小艺看世界的三种进入方式

1. **长按左镜腿「AI 快捷键」1 秒**——最直接的方式；
2. **语音唤醒小艺**后说"进入 / 打开小艺看世界"；
3. **短按 AI 快捷键唤起小艺**后，再下达指令。

> 交互要点：支持**手势代指 + 多轮对话**，并**支持插嘴打断**——
> 不必等它说完再提问，这一点在"边走边问"的场景里很关键。

## 三、看得见的用法

| 场景 | 能做什么 |
| --- | --- |
| 自然对话 | 聊天问答 |
| 识物 | 识别动植物 |
| 随身导游 | 讲解文物、景点历史 |
| 穿搭建议 | 服饰搭配参考 |
| 出国 | 实时翻译 |

## 四、按键与手势触控（官方定义）

**触控区：**

| 手势 | 作用 |
| --- | --- |
| 前滑 / 后滑 | 调节音量 |
| 轻触两下 | 播放 / 暂停 / 接听 |
| 轻触三下 | 下一曲 |

**电源键 / AI 快捷键：**

| 操作 | 作用 |
| --- | --- |

| 长按 3 秒 | 开机 |
| 长按 12 秒 | 强制重启 |

**拍摄键：**

| 操作 | 作用 |
| --- | --- |
| 按一下 | 拍照 |
| 长按 | 录像 |
| 按两下 | 切换手机 / 眼镜摄像头 |

| 类别 | 具体能力 |
| --- | --- |
| 控制手机 | 闹钟、日程、拨打电话 |
| 控制智能家居 | 开关灯、窗帘等 |
| 影像 | 语音拍照 / 录像 |
| 查询 | 电量与剩余容量 |

## 六、鸿蒙生态联动

- **靠近即连**（免配对流程）；
- **手表协同**；
- **鸿蒙智家设备控制**——眼镜成为全屋智能的一个语音入口；
- 通过「**华为眼镜**」App 发现、连接与管理设备，支持小艺对话 / 翻译、照片视频自动导入、
  视频通话与直播时切换摄像头。

## 七、与"华为智能眼镜 2"的区别（易混淆）

| 产品 | 能否拍照 / 显示 | 小艺能力 |
| --- | --- | --- |
| **华为 AI 眼镜**（AIL-G01） | 能（1200 万摄像头 + 第一人称视角） | 完整小艺看世界、识物、翻译、支付 |
| **华为智能眼镜 2**（纯音频） | 不能 | 小艺翻译、智慧播报、颈椎健康等 |

> 选购提示：想做"视觉 + 小艺看世界"，必须选 **AI 眼镜**；只要音频与播报，纯音频款即可。

## 八、使用建议与边界

**建议：**

1. 把**长按 1 秒**练成肌肉记忆——这是小艺看世界最高频的入口；
2. 问物体时**先指向再提问**（手势代指），比用语言描述更准；
3. 出国场景提前确认翻译语言对是否在支持范围内。

**边界：**

- 有**明确的手机系统版本门槛**（HarmonyOS 6.0.0.130+ 且限部分机型）；
- 视觉识别依赖摄像头取景条件，逆光、遮挡、远距离会影响准确率；
- 摄像头类产品在部分场所（涉密区域、更衣室等）受使用限制，请遵守当地规定与他人隐私；
- 续航为"综合续航"口径，**长时间连续使用视觉交互会明显短于 12 小时**。
