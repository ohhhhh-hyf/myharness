# 耳机、手表与智慧屏上的小艺

> 小艺不止在手机上。耳机用手势、手表用按键与语音、智慧屏用遥控器，让"唤醒入口"
> 贴合各自的设备形态；多设备同时在场时由**协同唤醒**决定谁来应答。

## 一、耳机：从"听"到"办"

### 1. 两种唤醒方式（默认都是关闭的）

| 唤醒方式 | 说明 |
| --- | --- |
| **手势控制** | 通过耳机手势触发语音助手 |
| **语音唤醒** | 说出唤醒词"**小艺小艺**" |

> **最常见的"喊不出来"原因**：这两种唤醒方式**默认关闭**，必须在华为智慧生活 /
> 华为智慧音频 App 中手动开启。开箱即用是做不到语音唤醒的。

- **适用系统**：HarmonyOS、iOS、Android；
- **支持语音唤醒的型号**：FreeBuds Pro 5、FreeClip 2 系列、FreeBuds 7i、FreeBuds 6、
  FreeBuds Pro 4、FreeClip、WATCH Buds 系列等。

### 2. 按住说话与连续对话

| 能力 | 支持型号 | 说明 |
| --- | --- | --- |
| **按住说话** | FreeBuds Pro 5、FreeClip 2 系列 | 长按耳机 → 说话 → 松手得到回答 |
| **连续对话** | FreeBuds Pro 5、FreeClip 2 系列 | 约 **10 秒**内可连续追问，无需重复唤醒 |

### 3. AI 键：直达小艺智能体

| 项目 | 说明 |
| --- | --- |
| 操作 | **长按 AI 键触控区域** |
| 能力 | **小艺帮接**、**通话摘要**（摘要以通知形式发送） |
| 型号与固件 | FreeBuds Pro 5（HarmonyOS 6.1.0.272+）、FreeClip 2 典藏版（6.1.0.352+）、FreeClip 2（6.1.0.370+） |
| 前提 | 连接 **HarmonyOS 6.1 及以上**华为设备 |
| 适用区域 | **中国大陆** |

> **一个容易踩的坑**：AI 键连接**安卓 / iOS 设备时操控的是豆包智能体**，
> 只有连 HarmonyOS 6.1+ 华为设备才走小艺。换手机后"AI 键变笨了"通常是这个原因。

**耳机端其他小艺能力**：小艺帮接、通话摘要、**随口记**。

## 二、智能手表：腕上小艺

| 项目 | 说明 |
| --- | --- |
| 唤醒方式 | **长按手表下键**；或语音"小艺小艺" |
| 设置页可配 | 按键唤醒、语音唤醒、连续对话、音色、**协同唤醒** |
| 常用能力 | 设闹钟、户外跑步、查天气、**健康数据分析** |
| 新一代能力（WATCH 6 系列"腕上小艺"） | 健康指标解读、腕上控家、实时翻译 |
| 协同地位 | 协同唤醒中**手表翻腕亮屏优先级最高**（焦点设备优先） |

## 三、智慧屏：客厅入口

| 项目 | 说明 |
| --- | --- |
| 唤醒方式 | 语音"小艺小艺"；**遥控器语音键** |
| 设置路径 | 设置 > 小艺 > 唤醒（可配置协同唤醒、连续对话） |
| 音色 | 官方音色（女声、童声、少女、男声），并支持**同步手机录入的自定义音色** |
| 常见场景 | 影音搜索与播放控制、家庭场景控制、与手机/车机内容流转 |

## 四、多设备协同唤醒规则（官方设计）

1. **焦点设备优先**：手表翻腕亮屏 > 耳机佩戴中 > 手机亮屏 5 秒内；
2. **跨设备场景**：服务中的设备优先；默认排序 *有屏音箱 > 无屏音箱 > 智慧屏 > 车机 > 手机 > 平板 > 手表*；
3. **同类设备**：比较声强与声纹置信度。

也支持**语音指定设备**（如在多设备环境里点名用哪台设备的小艺）。

## 五、常见问题

| 问题 | 解答 |
| --- | --- |
| 耳机能直接唤起小艺吗？ | 支持 AI 键的型号可以，且能在通话场景直接触发帮接/摘要 |
| 为什么对着耳机喊"小艺小艺"没反应？ | 语音唤醒**默认关闭**，需在 App 中手动开启；另需确认型号在支持列表内 |
| 耳机 AI 键连安卓手机为什么不一样？ | 连接**安卓 / iOS 设备时操控的是豆包智能体**，仅连 HarmonyOS 6.1+ 华为设备才走小艺 |
| 能连续追问吗？ | 支持"连续对话"的型号（FreeBuds Pro 5、FreeClip 2 系列）约 **10 秒**内可连续追问 |
| 手表能独立使用小艺吗？ | 可以（唤醒、闹钟、天气、运动与健康问答等） |
| 智慧屏能用手机录入的音色吗？ | 支持同步自定义音色 |
| 为什么喊小艺后是多台设备同时响应？ | 不会同时应答——协同唤醒只让最合适的一台回应；可按需关闭个别设备的唤醒 |
| 车里/家里设备太多怎么管？ | 在各设备的"唤醒"设置里单独开关协同唤醒与语音唤醒 |
