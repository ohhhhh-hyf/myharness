# 小艺开放平台与智能体广场生态

> 小艺开放平台是鸿蒙生态官方的智能体开发与分发平台（2025-06-20 HDC 2025 推出），
> 开发者可在此开发、调试、上架智能体，并触达全鸿蒙终端；"天工计划"提供 10 亿元级激励。

## 一、平台概览

| 维度 | 内容 |
| --- | --- |
| 定位 | 鸿蒙生态官方智能体开发平台 |
| 推出时间 | 2025-06-20（HDC 2025） |
| 服务链路 | 开发 → 调试 → 分发上架 |
| 开发模式 | LLM 模式、工作流模式、A2A 模式 |
| 系统插件 | 开放 50+ 官方系统插件（天气、日历、地图、文件管理等） |
| 接入方式 | Agent、Skill、MCP 等多种接入 |
| 新能力（2026） | VibeCoding（自然语言极简开发）、生成式 A2UI、华为账号一键登录统一授权 |

### 三种开发模式

1. **LLM 模式**：大语言模型驱动，适合快速搭建问答类智能体；
2. **工作流模式**：可视化编排多步骤任务；
3. **A2A 模式**：直连第三方智能体，支持多智能体跨域协同。

## 二、智能体广场（分发与触达）

- 开发者构建的智能体可上架**小艺智能体广场**，触达手机、平板、智慧屏、车机、智能家居等全鸿蒙终端；
- **HarmonyOS 6** 发布后，首批 **80 多个应用智能体**上架，覆盖教育医疗、娱乐互动、生活服务等场景（旅行规划、值机选座、点外卖等）；
- 截至 **2026 年 6 月**：平台累计上架 **2000+ 鸿蒙智能体**，接入 **500+ 生态伙伴精选 Skills**；
- **流量分发**：按用户需求与意图**公平分发**，保障开发者利益共享。

### 已入驻代表

DeepSeek-R1、Kimi、讯飞晓医、AiPPT.cn 等头部 AI 厂商与工具类智能体。

### 生态伙伴进展

- 腾讯已有 60 多款应用上架；
- 阿里、美团、字节等在加速适配。

## 三、商业化与变现

- 集成**华为 IAP 收银台**，支持付费技能、订阅、内购等变现模式；
- 平台侧提供流量分发与运营支持。

## 四、"天工计划"开发者激励

| 项目 | 内容 |
| --- | --- |
| 总投入 | **10 亿元**资金与资源 |
| 目标 | 孵化超 1 万个 AI 原生元服务、1 千多种意图框架/MCP、5 千多个智能体 |
| 单智能体激励 | 最高 **75 万元**现金 |
| 单开发者累计 | 最高 **200 万元** |
| 参与条件 | 企业开发者实名认证；账号注册地在中国大陆；需在 **2026-10-31 前**完成开发并上架 |

## 六、开发者上架流程（概览）

```text
1. 注册华为开发者账号（企业实名）
2. 小艺开放平台创建智能体 → 获取 agentId
3. 选择开发模式（LLM / 工作流 / A2A）配置技能
4. 真机调试（手机/平板，境内联网）
5. 绑定应用包名 → 提交审核 → 上架智能体广场
6. 分发运营 + 变现（IAP）与激励申报
```

## 七、常见问题

| 问题 | 解答 |
| --- | --- |
| 个人开发者能参加吗？ | 天工计划要求企业开发者实名认证 |
| 智能体上架要多久？ | 取决于审核，建议预留时间并对照 2026-10-31 激励截止 |
| 流量怎么来？ | 平台按意图与需求公平分发，可通过语音唤起、广场入口触达 |
| 能收费吗？ | 可以，集成华为 IAP 支持付费技能、订阅与内购 |
