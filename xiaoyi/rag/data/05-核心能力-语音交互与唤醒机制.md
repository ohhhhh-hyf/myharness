# 语音交互与唤醒机制

> 小艺支持多种唤醒方式（语音、按键、手势、小艺球），并在多设备并存时通过"协同唤醒"只让最合适的设备应答；
> 唤醒词与声纹等生物特征全部在设备本地处理。

## 一、唤醒方式

### 1. 手机 / 平板上的四种唤醒方式（官方口径）

| 唤醒方式 | 说明 |
| --- | --- |
| **语音唤醒** | 默认唤醒词"**小艺小艺**" |
| **长按屏幕底部导航条** | **锁屏状态也可用** |
| **长按电源键** | 约 1 秒 |
| **指关节圈选「问问小艺」** | 圈选屏幕内容后直接提问 |

### 2. 其他设备形态上的唤醒

| 唤醒方式 | 说明 |
| --- | --- |
| 语音唤醒 | 默认唤醒词"**小艺小艺**"；部分设备（如鸿蒙电脑）支持自定义唤醒词（4-6 个中文字） |
| 导航条长按 | 长按屏幕底部导航条（系统级入口） |
| 桌面小艺球 | 点击桌面悬浮小艺球 |
| 键盘智慧键 | 鸿蒙电脑专属 |
| 手势唤醒 | 部分设备支持 |
| 方向盘右侧按键 | 车机（见《车载小艺与腕上小艺》） |
| 长按耳机 AI 键 | 耳机（见《耳机手表与智慧屏上的小艺》） |
| 长按镜腿 AI 快捷键 1 秒 | AI 眼镜（见《小艺在 AI 眼镜上的能力》） |

## 二、小艺导航条：手机端最核心的入口

HarmonyOS 5 起引入的**常驻屏幕交互 UI**，不只是"唤醒按钮"：

| 操作 | 作用 |
| --- | --- |
| **长按**导航条 | 在任意界面唤醒小艺进行交流 |
| **左右横滑** | 快速切换应用 |
| **点击** | 返回（需开启：设置 > 系统 > 系统导航 > 点击导航条返回） |
| **拖拽**文本 / 图片 / 文件到导航条 | **投喂给小艺**做摘要、表格提取、图片翻译等智能分析 |

**能不能关掉**：导航条本身是系统功能，**不可关闭**；但可以：

- 改用三键导航来隐藏它；
- 在「设置 > 系统 > 系统导航 > **关闭长按触发小艺对话**」中关闭唤醒能力（保留 UI）。

### 借助导航条的两个延伸入口

| 入口 | 触发方式 | 前提 |
| --- | --- | --- |
| **伴随式 AI** | **双击**导航条 | 需先开启"双击导航条触发伴随式AI"（设置 > 系统 > 伴随式AI）；HarmonyOS 6.1，Pura X Max 首发 |
| **小艺游戏面板** | 长按导航条 / 长按电源键 0.5 秒 / 语音唤醒 | 小艺 App **11.3.1.300+** |

> 导航条的"拖拽投喂"是很容易被忽略的高效用法：把文档拖到底部导航条，
> 比"先打开小艺再选文件"少好几步。详见《小艺办公与学习场景实操》。

## 三、唤醒设置路径（按系统版本）

| 系统版本 | 设置路径 |
| --- | --- |
| HarmonyOS 5 | 设置 > 小艺 > 唤醒 > 语音唤醒 |
| HarmonyOS 6 | 设置 > 小艺 > 唤醒与对话 > 语音唤醒 |

- 打开开关后按提示**录入唤醒词**（仅支持普通话，不支持方言与英文）；
- 语音唤醒灵敏度**可调**（部分版本支持在设置页滑动调节）；
- 升级 HarmonyOS 5 前需将智慧语音升级至 12.1.8.410 及以上，否则需重新打开开关并录入唤醒词。

## 四、多设备协同唤醒（官方设计规则）

多台华为设备同时听到"小艺小艺"时，由"智慧大脑"协同判断，**只选最合适的设备应答**，其余静默。

**优先级规则（由高到低）**：

1. **焦点设备优先**：手表翻腕亮屏 > 耳机佩戴中 > 手机亮屏 5 秒内；
2. **跨设备场景**：服务进行中的设备优先；默认设备排序为
   *有屏音箱 > 无屏音箱 > 智慧屏 > 车机 > 手机 > 平板 > 手表*；
3. **同类设备**：比较声强、声纹置信度。

**技能分发**：用户未指定设备时，系统按"设备与技能匹配度 + 使用习惯 + 置信度"选择应答设备；也支持语音指定设备名称。

## 五、进阶语音能力

| 能力 | 说明 |
| --- | --- |
| 连续对话 | 一次唤醒后连续下达多条指令（默认可能关闭，建议开启） |
| 小艺私语 | 安静场所把嘴靠近麦克风约 5 厘米轻声说话即可（HarmonyOS 5.0+） |
| 小艺自然聊 | 嘈杂环境稳定唤醒、轻声耳语可随时打断续聊（HarmonyOS 7，行业首发 AI 语音通路） |
| 方言自由说 | 自动甄别方言，**无需手动设置**；支持四川话、河南话、山东话、东北话、天津话、陕西话、贵州话、河北话、长沙话、粤语 |
| 声纹识别 | 识别家庭成员声音（如儿童触发专属模式） |

**方言能力边界**：

- 仅识别，**不支持方言语音播报**（播报统一用普通话）；
- 第三方测评显示粤语、四川话、东北话识别准确率约 84%–88%，混合方言（如粤普夹杂）支持薄弱；
- 蒙古话、朝鲜话、新疆话等不在支持范围内。

## 六、唤醒失败排查（官方四步法）

1. **检查开关**：确认语音唤醒已开启并正确录入唤醒词；
2. **清理后台 + 重启设备**；
3. **重新录入唤醒词**：在安静环境录制（"重新录入唤醒词"入口）；
4. **检查麦克风**：
   - 用系统录音机录制并戴有线耳机回放，判断左右声道是否异常；
   - 检查底部麦克风（USB 与 SIM 卡槽中间）是否被贴膜、保护壳遮挡。

补充检查项：

- 是否被**其他设备协同唤醒**接管（多设备共存时）；
- 权限与省电限制：设置 > 应用 > 小艺 > 权限，允许麦克风，关闭省电限制；
- 场景限制：**通话、录音、录屏、游戏全屏**等麦克风被占用时无法唤醒；勿扰/静音、省电模式可能影响唤醒效果。

仍未解决：小艺 App > 右上角头像 > 帮助和反馈 > 问题和建议（勾选共享日志），或拨打华为热线 **950800**。

## 七、常见唤醒问题速查表

| 现象 | 可能原因 | 处理 |
| --- | --- | --- |
| 完全唤不醒 | 开关未开/录入异常 | 重新开启并录入唤醒词 |
| 时好时坏 | 环境嘈杂、距离过远 | 2 米内清晰说出唤醒词，说完稍作停顿 |
| 多设备乱应答 | 协同唤醒分配 | 关闭非必要设备的语音唤醒，或语音指定设备 |
| 特定场景失效 | 麦克风被占用 | 退出通话/录音/录屏/全屏游戏后重试 |
| 部分口令无响应 | 口令已下线 | 以当前系统版本支持为准 |
| 长按导航条没反应 | 该开关被关闭 | 设置 > 系统 > 系统导航 > 检查"长按触发小艺对话"是否关闭 |
| 想把底部导航条去掉 | 系统 UI 不可关闭 | 改用**三键导航**隐藏，或在上述路径关闭其唤醒能力 |
