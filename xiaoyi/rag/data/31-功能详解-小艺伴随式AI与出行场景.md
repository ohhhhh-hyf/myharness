# 小艺伴随式 AI 与出行场景

> "伴随式 AI"是小艺从"你问我答"走向"懂你所想、应你所需"的形态：不需要用户发起完整指令，
> 系统根据行程、时间与路况在关键节点主动给出提醒与一键操作入口。出行是这条路线最典型的落地场景。

## 一、什么是伴随式 AI

| 维度 | 说明 |
| --- | --- |
| 交互形态 | 不依赖完整语音指令，在**购票页、出发前、到达后**等关键节点主动推送卡片 |
| 唤起方式 | **双击小艺导航条**（部分场景自动触发） |
| 技术底座 | 小艺 Agentic 自演进架构，支持快慢思考融合、记忆与自主学习 |
| 首发机型 | HUAWEI Pura X Max 系列，HarmonyOS 6.1 |
| 芯片平台 | 麒麟 9030 Pro，软硬芯云协同实现更低功耗与更低时延 |

与《小艺建议与主动服务》的区别：主动服务偏向"桌面卡片与提醒"，伴随式 AI 更强调
**在具体任务链路中替你完成下一步操作**（如直接唤起打车并填好起终点）。

## 二、通勤场景

- **路况预警**：根据通勤时间与地址提前查询路况，拥堵时推送高德路况预警；
- **智能出发提醒**：结合实时路况反推"该几点出发"，而不是固定闹钟；
- **一键导航**：自动填入出发地与目的地，点一下即开始导航；
- **习惯学习周期**：通勤习惯需约 **14 天**学习才能形成稳定的习惯标签。

> 提示：刚换机或刚开启功能时"没有通勤提醒"属正常现象，等待习惯模型建立即可。

## 三、差旅场景

差旅是伴随式 AI 能力最完整的场景，覆盖"订票 → 出发 → 到达"全链路：

1. **自动识别并记录行程**：在购票成功页（机票 / 火车票 / 酒店）**双击小艺导航条**，
   自动识别并记录订单信息，无需手动录入；
2. **出发前**：根据机 / 火 / 酒信息查询路况，提供高德智能出发提醒与**一键打车**；
3. **到达后**：推送滴滴**接驾耗时提醒**（含上车点引导）；
4. **行程整合**：出差场景可自动整合航班、酒店、租车信息，生成**行程时间轴**。

## 四、支持的出行类应用

| 类别 | 应用 |
| --- | --- |
| 综合旅行 | 同程旅行、携程、去哪儿、飞猪 |
| 火车票 | 智行火车票、铁路 12306、高铁管家 |
| 航班 | 航旅纵横 |
| 商旅 | 慧通差旅 |
| 导航 | 高德地图（路况预警、智能出发提醒、机场室内导航） |
| 打车 | 滴滴出行（一键打车、接驾耗时提醒） |

## 五、基础主动服务中的出行能力

即使不依赖伴随式 AI，以下基础能力在较早版本已可用（通过**识屏**实现）：

| 能力 | 说明 |
| --- | --- |
| 导航 | 识屏后自动调用最常用导航软件并规划路线 |
| 打车 | 自动提取地址、调用最常用打车软件并填充出发地 / 目的地 |
| 航班查询 | 查询航班动态 |
| 打开网址 / 打电话 | 基础服务调用 |

## 六、意图框架串起的"场景服务链"

以一次出差为例，多个应用通过鸿蒙**意图框架**串联成一条完整的服务链：

```
航旅纵横（电子登机牌）
  → 飞常准（登机口变更提醒）
  → 高德地图（机场室内导航）
  → 滴滴出行（到达后打车推荐）
```

用户感知到的是"小艺在恰当的时候提醒我"，实际是多个生态伙伴的服务按意图被调度。

## 七、使用建议与边界

**建议：**

1. 在设置中**开启伴随式 AI / 小艺建议**，并授权位置与日历（路况与行程推断的前提）；
2. 保持常用出行 App 为最新版本，并**允许通知**（提醒依赖通知通道）；
3. 购票后**主动双击小艺导航条**录入行程，这是差旅能力生效的关键动作；
4. 通勤用户给系统约两周学习时间。

**边界：**

- 行程识别依赖合作 App 的页面结构，**非合作应用的订单无法自动识别**；
- 路况与打车提醒属于建议性质，**不做支付类决策**，下单前仍需用户确认；
- 通勤习惯标签、差旅链路等能力**有明确机型与系统版本门槛**（见《小艺功能版本门槛与升级速查》）；
- 位置与行程数据属敏感信息，隐私控制方式见《小艺的记忆与隐私实操》。

## 八、常见问题

| 问题 | 解答 |
| --- | --- |
| 为什么我购票后没有自动记录行程？ | 需手动**双击小艺导航条**触发识别；且该应用需在支持列表内 |
| 通勤提醒多久能生效？ | 通勤习惯约需 **14 天**学习形成标签 |
| 支持哪些机型？ | 伴随式 AI 首发于 Pura X Max（HarmonyOS 6.1）；基础识屏类出行能力覆盖更广 |
| 能自动帮我打车付款吗？ | 不能。会唤起打车并填好信息，**支付与确认始终由用户完成** |
| 导航用哪个地图？ | 默认调用**你最常用的**导航软件；路况预警数据来自高德 |
