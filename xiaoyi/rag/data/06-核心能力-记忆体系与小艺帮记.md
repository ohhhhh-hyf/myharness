# 记忆体系与小艺帮记

> 记忆是小艺近年最重要的升级方向之一，包含三条主线：
> **端侧个人记忆管理（小艺帮记）**、**座舱场景的个性化记忆**、**Agent 架构下的长期记忆与自学习（小艺 Claw）**。

## 一、小艺帮记：AI 记忆管家

**定位**：在"小艺记忆""小艺知识库"基础上升级而来的**信息收纳与管理**能力。

**支持环境**：手机、平板及鸿蒙电脑（HarmonyOS 5.1 及以上，需小艺 App 11.5.2.300 及以上）。

### 核心亮点

| 维度 | 能力 |
| --- | --- |
| 想记就记 | 随口记、识屏、分享、拖拽等 **6 种记录方式**；可存证件、日期、地址、订单、文件、图片、视频、网页链接等 |
| 找得超快 | 关键词搜索、**图片文字搜索**、**语义搜索**（说句话就能找到） |
| 整理省心 | 自动分类合集 + 自建专属合集 |
| 用得智能 | 基于存储内容问答、生成 **AI 播客音频**；鸿蒙电脑端支持**知识闪卡**生成 |
| 访问便捷 | 桌面快捷方式、小艺搜索、语音唤醒等 **4 种入口** |

### "我的记忆"

支持记录以下常用信息与个人偏好：

- 重要日、卡证、地址、事件、订单；
- 个人兴趣偏好（用于个性化服务）。

### HarmonyOS 6.1 热更新新增（2026-05）

- **身份验证**：查看身份证、银行卡等敏感信息需**指纹/人脸或锁屏密码**验证；
- **同步收藏**：应用内收藏内容自动归集（已支持华为浏览器等），并提供 **AI 摘要、AI 问答、AI 播客**。

### 安全设计

- 采用 **TEE 可信执行环境**，数据本地处理。

## 二、与小艺帮记相关的能力

- **小艺记忆（旧版）**：旧版功能已并入小艺帮记，官方发布过升级提示；
- **帮记与帮写联动**：帮记负责"存"，帮写负责"用"（润色、改写、生成思维导图等，详见《小艺帮写与办公创作》）。

## 三、长期记忆与自进化：小艺 Claw

| 时间 | 能力 |
| --- | --- |
| 2026-04（先锋版） | 支持**深度记忆和自我学习**，"越用越懂你" |
| 2026-04-29 更新 | 引入**自进化能力**：记忆用户偏好、沉淀可复用技能 |
| 模型与上下文 | 接入 **DeepSeek V4**，百万级超长上下文 |
| 适用环境 | HarmonyOS 6 及以上设备 + 小艺 App 对应版本 |
| 安全认证 | 通过中国信通院 Claw 类智能体安全专项评测（详见安全文档） |

**人格化能力**：小艺 Claw 具备多种人格设定（如"办公搭子"），可处理文档编辑、撰写 PPT、数据制表等任务。

## 四、Agent 架构下的记忆（HDC 2026）

- 小艺升级为鸿蒙系统"智慧大脑"，采用**双循环自演进架构**：
  *外循环：快慢自适应 — 记忆自学习 — 执行自动化 — 反思自迭代*；
- 凭借**长期记忆与上下文理解能力**，授权后可调用 **200+ 项系统级数据**（日程、文件、地点、睡眠、通勤偏好等）；
- **车载场景**（2026-05-28，问界 M9 首发）：重构上下文引擎，提升思考质量与记忆能力，支持专属个性化记忆、模糊语义理解、多目的地行程规划、方言自由说等。

## 五、用户视角：记忆能力怎么用

1. **随手记**：对手机说"记一下 XXX"，或识屏/拖拽内容给小艺帮记；
2. **找东西**：直接问"上次我记的那个快递单号是多少"（语义搜索）；
3. **用记忆**：让小艺基于已存内容生成摘要、播客、闪卡或回答问题；
4. **管隐私**：敏感信息查看需验证；可在隐私设置中管理记忆数据与端侧/云侧处理偏好。

## 六、常见问题

| 问题 | 说明 |
| --- | --- |
| 小艺帮记和"小艺记忆"的关系？ | 帮记是记忆能力的升级形态，旧版记忆已并入 |
| 数据存在哪里？ | 端侧处理为主，采用 TEE 可信执行环境 |
| 为什么查看证件要验证？ | HarmonyOS 6.1 起对敏感信息启用身份验证 |
| 记忆会不会上云？ | 取决于功能与设置，可开启本地 AI 能力避免数据上云（详见安全文档） |
