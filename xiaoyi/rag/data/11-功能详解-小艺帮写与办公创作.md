# 小艺帮写与办公创作

> "帮写"是小艺内容创作能力的总称：从润色改写、录音转文，到文档、表格、PPT、思维导图的全套办公产出，
> 再到 HarmonyOS 7 的对话式文档编辑与小艺任务端侧 Agent。

## 一、小艺帮写（写作与内容创作）

**核心能力**：

- **写作辅助**：文案润色、改写、扩写、缩写；
- **思维导图**：把内容整理为结构化脑图；
- **录音转写**：备忘录中记录语音文档 → 小艺帮写转文本 → 一键生成摘要 → 智能润色排版 → **声纹识别标记发言人**；
- **联动帮记**：帮记负责"存"，帮写负责"用"。

**典型场景**：会议记录整理、周报素材、文案改写、口头笔记转文档。

## 二、小艺文档助理（全能 AI 办公伙伴）

**适用**：HarmonyOS 5.0 及以上，系统界面含**文档阅读、文档创作、文档工具**三类功能。

### 1. 文档阅读类

| 功能 | 说明 |
| --- | --- |
| 摘要提炼 | 支持 PDF/Word/Excel/PPT、网页链接、音视频，快速生成摘要（论文、财报、PPT/Excel） |
| 思维导图 | 自动提炼文档/网页/音视频关键信息，生成结构化脑图；支持单文档或多文档 |
| 文档问答 | 对文档细节精准提问、询问整体框架、多文档关联分析 |
| 文档比对 | 合同校对、文稿初版与终版差异对比 |

### 2. 文档创作类

| 功能 | 说明 |
| --- | --- |
| Word 撰写 | 智能润色/补写/修改排版、多文件内容整合填充、按模板生成并排版 |
| Excel 表格 | 全新表格设计生成、数据填充、多文件表格信息整理（PDF/Word/网页 → 表格） |
| PPT 生成 | 由文档或网页链接生成 PPT，可自定义页数、场景（研究报告、商业提案、培训教学）与模板（简约、商务、学术、科技） |
| 格式转换 | PDF→Word、Word/PPT→PDF、音视频→TXT、网页→Word/PDF、图片→Excel 等 |

### 3. 学习/教学辅助

- **课件生成**：根据文档或网页链接生成教学课件（标准课堂/情境探究模式）；
- **教案生成**：上传教材生成教案，可选课时；
- **知识闪卡**（鸿蒙电脑）：基于科学记忆法把学习资料变成填空、选择、问答闪卡；
- **小艺深度研究**：跨格式解析文本、图像与 PDF，输出**带引用的结构化研究报告**；
- **小艺深度解题**：拍照解题、批改作业、收录错题。

## 三、鸿蒙电脑上的办公增强

- 可与 **WPS Office、亿图脑图 MindMaster** 协同，自动创作演示文稿、思维导图；
- 本地模型离线问答（数据安全优先场景）；
- 知识闪卡生成。

## 四、HarmonyOS 7：办公能力再升级

| 新能力 | 说明 |
| --- | --- |
| **小艺任务**（端侧 Agent） | 端到端办公任务：文件智能归类、内容感知批量重命名（读取合同甲方/日期/金额）、重复文件清理 + **语义回滚**（说"撤销刚才的文件整理"即可回退）、日报/周报生成、一句话智能填表 |
| **对话式文档编辑**（Mate XT2） | 语音指令或手写笔划词实现意图级编辑，全篇联动优化；支持改标题、重构逻辑、润色段落、调整数据、生成图表 |
| **休眠态跨端办公** | 手机小艺远程调取休眠/合盖 PC 中的文件，支持翻译、摘要、思维导图并回传手机 |

## 五、使用建议

1. **入口**：小艺 App 中说"帮我写…"；或把文档拖到导航条交给小艺；
2. **格式支持**：摘要与转换对格式有要求，图片中的文字识别能力有限（部分场景"看不见图片里的字"）；
3. **复杂文档**：长文档建议分段处理，或先用文档问答确认理解；
4. **产出校对**：生成内容需人工复核（尤其合同、报表类）。

## 六、能力边界

- 纯文字生成类任务在部分版本/入口上能力有限，建议使用专门入口（小艺帮写、文档助理）；
- 小艺修图等能力有版本门槛（详见版本对照文档）；
- 生成内容受合规策略约束（不符合法规的指令会被拦截）。
