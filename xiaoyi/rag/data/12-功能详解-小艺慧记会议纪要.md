# 小艺慧记：会议纪要与实时转写

> 小艺慧记是鸿蒙系统的 AI 会议纪要能力：实时转写、发言人区分、会中摘要、待办提取、智能问答，
> 会后可一键导出 Word 文档。2025 年 5 月随鸿蒙电脑首发，现覆盖 HarmonyOS 6.0 及以上设备。

## 一、支持范围

| 维度 | 说明 |
| --- | --- |
| 首发 | 2025 年 5 月，鸿蒙电脑 |
| 当前覆盖 | HarmonyOS 6.0 及以上：华为手机、平板及 PC |
| 适用机型 | Mate 80 系列、Mate X7 等（逐步适配，部分设备可能暂未支持） |
| 费用 | HarmonyOS 5.0 及以上为**免费服务** |
| 时长上限 | 单次最长 **5 小时**录音，达上限自动停止 |
| 网络要求 | **需联网**（调用云服务器能力） |
| 语言支持 | 当前仅支持**中文普通话**转写，暂不支持方言及其他语种 |

## 二、核心功能

### 1. 实时语音转文字

- 边录音边转写，自动按**发言人和发言顺序**分段显示；
- 通过**麦克风**或**系统媒体音**收音，可在腾讯会议、钉钉等平台会议中实时转写。

### 2. 发言人区分

- 自动识别不同发言人音色并拆分内容；
- 可**关注特定发言人**、**修改发言人名称**；
- 可提前**导入参会人名单**提升识别精准度。

### 3. 会中摘要与总结

- 发言内容达 200 字可按段落生成摘要（支持自动/手动刷新）；
- 可生成关注发言人的发言总结；
- 支持划重点、备注、截图。

### 4. 待办事项提取

- 自动提炼**核心结论、决策点和待办事项**；
- 标注**时间节点与责任人**；
- 待办可一键**添加至日程**。

### 5. 智能提醒

- 可设置触发关键词（如自己的名字）；
- 会议提到关键词时在手机等设备推送提醒——适合中途离席场景。

### 6. 慧记智能问答

- 会议中在底部对话框提问（如"前面主要讲了什么"）；
- 小艺总结要点并可**定位原文**。

## 三、使用方法

### 启动方式

- 对设备说："**小艺小艺，开启小艺慧记**"（或称"开启会议模式"）。

### 推荐设置

1. 设置 → 智慧助手 → 小艺 → **应用服务模式**切换为**全量模式**；
2. 开启"实时转写""发言人区分""待办事项提取"等选项。

### 会后处理

- **一键导出 Word 文档**；
- 内容也可保存至备忘录的"**小艺慧记**"文件夹查看。

## 四、使用限制与已知问题

| 限制 | 说明 |
| --- | --- |
| 通话场景 | 暂**不支持**微信/QQ 语音视频通话及运营商通话内容的识别 |
| 发言人识别 | 音色相近、多人同时发言时可能出错 |
| 语言 | 仅中文普通话；方言与其他语种不支持 |
| 网络 | 必须联网 |
| 机型 | 功能逐步适配，部分设备暂未支持 |

## 五、适用场景

- **线下会议**：麦克风收音，全程转写；
- **线上会议**：媒体音收音，与腾讯会议/钉钉等平台并用；
- **访谈/听课**：发言人区分 + 摘要 + 待办提取；
- **中途离席**：关键词提醒避免漏掉重点。

## 六、常见问题

| 问题 | 解答 |
| --- | --- |
| 为什么识别不准？ | 检查是否导入参会人名单、是否多人同时发言、环境噪音是否过大 |
| 能识别通话内容吗？ | 微信/QQ 语音视频通话与运营商通话暂不支持 |
| 录音能存多久？ | 单次上限 5 小时，达上限自动停止 |
| 转写内容在哪看？ | 小艺慧记内、备忘录"小艺慧记"文件夹，或导出的 Word |
