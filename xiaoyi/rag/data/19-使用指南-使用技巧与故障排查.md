# 使用技巧与故障排查 FAQ

> 本文汇总日常使用的关键设置、效率技巧与常见问题排查路径。多数"小艺不够智能"的体验，
> 实际与**默认关闭的连续对话 / 后台权限 / 全量模式**有关。

## 一、三个必做设置

| 设置 | 路径 | 作用 |
| --- | --- | --- |
| **语音唤醒** | 设置 > 小艺 > 唤醒与对话 > 语音唤醒（HarmonyOS 6） | 开启"小艺小艺"唤醒 |
| **全量模式** | 小艺 App > 设置 > 应用服务模式 > 全量模式 | 解锁跨应用操作、"帮帮忙"等高阶能力 |
| **连续对话** | 小艺设置中开启 | 一次唤醒连续下达多条指令 |

## 二、效率技巧

1. **多指令一次执行**："打开静音模式、关闭移动数据、把亮度调到最低"；
2. **可见即可说**：直接念屏幕上的按钮名称即可操作；
3. **拖拽执行**：把图片/文件拖到底部导航条 → 提取表格、文字、生成摘要；
4. **屏幕可见可问**：有地址说"导航到这"，有电话说"拨打这个号码"；
5. **场景自动化**："每天晚上 23 点自动开启静音、关闭 WiFi、调低亮度"；
6. **找手机**：喊"你在哪里"（最大音量响铃 + 闪光灯）；
7. **小艺私语**：图书馆等安静场合，靠近麦克风 5 厘米轻声说；
8. **长截图**：说"截取长截图"自动拼接。

## 三、唤醒问题排查（四步法）

1. **检查开关**：语音唤醒是否开启、唤醒词是否录入（仅普通话）；
2. **清理后台并重启设备**；
3. **重新录入唤醒词**：安静环境重新录制；
4. **检查麦克风**：系统录音机自测左右声道；检查底部麦克风是否被贴膜/保护壳遮挡。

补充：

- 多设备共存时确认**是否被其他设备协同唤醒**；
- 检查麦克风权限与省电限制；
- 注意场景限制：通话、录音、录屏、游戏全屏时无法唤醒；勿扰/静音、省电模式会影响效果。

仍无法解决 → 小艺 App > 头像 > 帮助和反馈 > 问题和建议（勾选共享日志），或拨打 **950800**。

## 四、功能"用不了"排查

| 现象 | 可能原因 | 处理 |
| --- | --- | --- |
| 功能入口找不到 | 系统/App 版本不够 | 对照《各版本 HarmonyOS 小艺特性对照》检查版本门槛 |
| 跨应用任务失败 | 未开启全量模式 / 第三方适配不足 | 开全量模式；确认目标 App 在支持列表 |
| 方言识别不准 | 混合方言、口音 | 使用普通话或标准方言短句；注意不支持方言播报 |
| 语音修图无反应 | 缺少识屏/图库权限 | 设置 > 智慧助手 > 小艺 > 识屏权限 |
| 修图次数受限 | 云侧每日次数限制 | 次日再试或降低指令复杂度 |
| 慧记转写异常 | 未开实时转写；多人抢话；环境噪音 | 开启对应选项、导入参会人名单 |
| 摘要未生成 | 通话少于 100 字或超 2 小时 | 属功能限制 |
| 口令无响应 | 老口令已下线 | 以当前版本支持为准 |

## 五、高频 FAQ

| 问题 | 解答 |
| --- | --- |
| 小艺支持方言吗？ | 支持约 10 种方言识别（四川、河南、山东、东北、天津、陕西、贵州、河北、长沙、粤语），**不支持方言播报** |
| 能帮我写周报吗？ | 在部分版本上纯文字生成能力有限，建议使用小艺帮写/文档助理入口 |
| 上下文能记住多久？ | 单轮对话内可关联；跨会话长期记忆依赖小艺帮记/小艺 Claw（需相应版本） |
| 小艺会偷听吗？ | 唤醒在本地完成，唤醒前不上传音频（详见安全文档） |
| 数据能不上云吗？ | 可开启"本地 AI 能力"或使用本地模型（鸿蒙电脑），详见隐私设置 |
| 换机/多设备会冲突吗？ | 支持协同唤醒与指定设备；建议按需关闭部分设备唤醒 |
| 老人/儿童能用吗？ | 支持声纹识别与儿童专属模式；基础语音操作对老人友好 |

## 六、反馈与获取帮助

- **应用内反馈**：小艺 App > 帮助和反馈 > 问题和建议（建议勾选共享日志）；
- **官方支持**：华为消费者业务官网支持中心搜索"小艺"；
- **热线**：950800；
- **门店检测**：怀疑硬件（麦克风）问题时，携带购机凭证前往华为客户服务中心。
