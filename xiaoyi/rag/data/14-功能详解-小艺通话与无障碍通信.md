# 小艺通话：帮接、摘要与无障碍通信

> 小艺通话在 HarmonyOS 5.0 上线，随原生鸿蒙基于大模型升级，
> 新增通话翻译、通话摘要与通话声音修复；同时为听障、语障、视障用户提供无障碍通信能力。

## 一、小艺帮接（自动接听）

**适用**：不方便接听电话（开会、看电影、上课等）时。

| 能力 | 说明 |
| --- | --- |
| 自动接听 | 可设置**响铃多久后自动接听** |
| 开场语 | 支持**自定义开场语** |
| 防漏接/防骚扰/防打扰 | 按场景过滤与提醒 |
| 语音转文字 | 通话语音实时转写为文本 |
| 文字转语音 | 输入文字转语音发送给对方 |

## 二、通话摘要

- 通话结束后**自动生成摘要**；
- 查看位置：**通知中心、电话通话记录、备忘录或小艺通话记录**；
- 支持**一键生成摘要**或**自动生成**（可指定号码或所有通话）；
- 限制：**通话内容少于 100 字或超过 2 小时将无法生成摘要**。

## 三、通话声音修复

- 通过 AI 实时分析优化语音，**保留原生音色**并提升清晰度；
- 已整合进小艺通话；
- 面向**语障用户**：帮助发声障碍者更清晰交流；
- 荣誉：入选"2025 年助残科技创新案例"与"2025 年科技助残应用场景"。

## 四、无障碍通信能力

### 1. 听障用户

- 语音与文字**双向实时转换**：对方语音转文字显示，用户输入文字转语音传给对方；
- 通话结束自动生成摘要与待办事项。

### 2. 语障用户

- **小艺声音修复**：AI 优化发音清晰度，保留个人音色。

### 3. 视障用户：小艺看世界

- 搭配**华为 AI 眼镜**，实现视觉信息向语音实时转化；
- 可识别**障碍物、红绿灯、文字资料**等；
- 具备**主动预警**能力（如提前播报路况）；
- 其他无障碍基础能力：屏幕朗读、小艺字幕、放大手势、高对比度文字、色彩校正。

## 五、耳机端快捷操作

- **HUAWEI FreeBuds Pro 5、FreeClip 2** 等耳机连接 **HarmonyOS 6.1 及以上**设备后：
  - 长按耳机 **AI 键**，在来电、通话场景下可启动**小艺帮接**和**摘要功能**；
  - 通话摘要以通知形式发送。

## 六、适用场景汇总

| 场景 | 推荐用法 |
| --- | --- |
| 开会中不便接电话 | 小艺帮接（自定义开场语 + 防打扰） |
| 错过重要通话内容 | 通话摘要 + 待办提取 |
| 听力障碍沟通 | 语音↔文字双向转换 |
| 发声障碍沟通 | 小艺声音修复 |
| 视障出行 | 小艺看世界（AI 眼镜）主动预警 |
| 运动/双手不便 | 耳机 AI 键一键帮接 |

## 七、常见问题

| 问题 | 解答 |
| --- | --- |
| 摘要为什么没生成？ | 通话少于 100 字或超过 2 小时不支持生成 |
| 帮接会漏掉电话吗？ | 支持防漏接设置；重要来电可设置例外 |
| 微信/QQ 通话能转写吗？ | 慧记与通话转写暂不支持微信/QQ 语音视频通话 |
| AI 眼镜是必需的吗？ | 小艺看世界需要华为 AI 眼镜；其他无障碍能力为系统内置 |
