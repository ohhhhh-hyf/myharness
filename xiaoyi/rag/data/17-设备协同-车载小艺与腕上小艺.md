# 车载小艺与腕上小艺

> 小艺不只在手机上：在鸿蒙座舱里它是"车内管家"，在手表上它是"腕上助手"，
> 二者通过分布式能力与手机等设备实现任务流转。

## 一、车载小艺：鸿蒙座舱里的智能助手

### 1. 鸿蒙座舱能力（HarmonySpace / MoLA 架构）

| 版本 | 要点 |
| --- | --- |
| 鸿蒙座舱 4.0（问界 M9 等） | 基于 HarmonyOS 分布式能力，手机、手表、平板、智慧屏与车机连接；导航、音乐、会议等应用流转；车载小艺升级为个性化助手，支持多模态交互 |
| 鸿蒙座舱 HarmonySpace 6（2026-04-23） | 行业首个**全场景聊天型 AI 助理「小艺智能体」**；发布 **MoLA 2.0 架构**，多模态感知引擎与**记忆模块深度融合** |
| 车载小艺"新大脑"（2026-05-28，问界 M9 首发） | 重构上下文引擎，提升思考质量与**记忆能力**；新增模糊语义理解、多目的地行程规划、**专属个性化记忆**、高情商对话、"小艺搜歌"、**方言自由说**、全场景跨端协同 |

### 2. 车载场景的核心能力

- **六音区声纹识别**：识别不同座位乘客的指令；
- **模糊语义理解与多轮对话**：更接近自然交流；
- **任务流转**：上车接续手机任务、下车同步回手机；
- **车家互联**：车机查看家门摄像头、归家途中提前开启空调/新风；
- **座舱操作占比**：早在 2023 年，**87.6%** 的座舱操作由小艺完成。

## 二、腕上小艺：手表端能力

### WATCH 6 系列"腕上小艺"

| 能力 | 说明 |
| --- | --- |
| 健康指标解读 | 基于手表健康数据提供解读与建议 |
| 腕上控家 | 在手表上控制智能家居设备 |
| 实时翻译 | 手表端实时翻译能力 |
| 语音交互 | 翻腕亮屏即可唤醒（多设备协同中的"焦点设备优先"） |

### 手表在协同唤醒中的地位

- **焦点设备优先**规则中，**手表翻腕亮屏**优先级最高（优先于耳机佩戴、手机亮屏）；
- 默认设备排序中手表位于末位（有屏音箱 > 无屏音箱 > 智慧屏 > 车机 > 手机 > 平板 > 手表）——即"就近与正在使用的设备优先"。

## 三、多设备任务流转示例

| 场景 | 流转方式 |
| --- | --- |
| 开车时记录事项 | 车机小艺应答 → 手机备忘录记录 |
| 车载摄像头抓拍 | 回家后在智慧屏上查看照片 |
| 运动时提醒 | 手表小艺提醒心率异常 |
| 手机任务上车 | 导航、音乐、会议自动接续到车机 |

## 四、协同唤醒规则（与车机/手表相关部分）

当多台设备同时听到"小艺小艺"：

1. **焦点设备优先**：手表翻腕亮屏 > 耳机佩戴中 > 手机亮屏 5 秒内；
2. **跨设备场景**：服务中的设备优先；默认排序 *有屏音箱 > 无屏音箱 > 智慧屏 > 车机 > 手机 > 平板 > 手表*；
3. **同类设备**：比较声强与声纹置信度。

也支持**语音指定设备名称**（如"用手机的小艺…"）。

## 五、常见问题

| 问题 | 解答 |
| --- | --- |
| 车机上的小艺和手机一样吗？ | 共享能力底座，车载版针对座舱场景强化（多音区、车控、流转） |
| 手表能独立使用小艺吗？ | WATCH 6 系列支持腕上小艺（健康解读、控家、翻译等） |
| 为什么车里喊小艺手机也响应？ | 协同唤醒按优先级选设备；可关闭部分设备的语音唤醒 |
| 车载小艺支持方言吗？ | 支持"方言自由说"（车载"新大脑"升级后） |
