# 车载小艺与腕上小艺

> 小艺不只在手机上：在鸿蒙座舱里它是"车内管家"，在手表上它是"腕上助手"，
> 二者通过分布式能力与手机等设备实现任务流转。

## 一、车载小艺：鸿蒙座舱里的智能助手

### 1. 鸿蒙座舱能力（HarmonySpace / MoLA 架构）

| 版本 | 要点 |
| --- | --- |
| 鸿蒙座舱 4.0（问界 M9 等） | 基于 HarmonyOS 分布式能力，手机、手表、平板、智慧屏与车机连接；导航、音乐、会议等应用流转；车载小艺升级为个性化助手，支持多模态交互 |
| 鸿蒙座舱 HarmonySpace 6（2026-04-23） | 行业首个**全场景聊天型 AI 助理「小艺智能体」**；发布 **MoLA 2.0 架构**，多模态感知引擎与**记忆模块深度融合** |
| 车载小艺"新大脑"（2026-05-28，问界 M9 首发） | 重构上下文引擎，提升思考质量与**记忆能力**；新增模糊语义理解、多目的地行程规划、**专属个性化记忆**、高情商对话、"小艺搜歌"、**方言自由说**、全场景跨端协同 |

### 2. 车载场景的核心能力

- **六音区声纹识别**：识别不同座位乘客的指令；
- **模糊语义理解与多轮对话**：更接近自然交流；
- **任务流转**：上车接续手机任务、下车同步回手机；
- **车家互联**：车机查看家门摄像头、归家途中提前开启空调/新风；
- **座舱操作占比**：早在 2023 年，**87.6%** 的座舱操作由小艺完成。

### 3. 多音区智慧感知（官方支持文档）

这是车载小艺与手机小艺最本质的差异——**同一句话，谁说的、对谁生效**。

| 能力 | 说明 |
| --- | --- |
| **多音区识别** | 利用多音区判定与防串扰技术，准确区分不同座椅用户的指令，互不干扰 |
| **音区定位** | 只说"打开车窗"即执行**主驾**车窗操作，**无需**说"主驾车窗" |
| **权限控制** | 驾驶相关设置**仅主驾可语音操控**；除主驾外的音区可自主开启 / 关闭 |
| **唤醒方式** | ① 说出"小艺小艺"；② **方向盘右侧按键**唤醒 |

- **适用范围**：中国大陆地区**鸿蒙智行全系车型**（硬件配置不同，能力有差异）；
- **对应版本**：官方文档标注 HarmonyOS 4.0 / 4.2 / 4.3。

> 权限控制这条值得单独理解：它不是"识别不出副驾"，而是**设计上不允许**副驾改驾驶相关设置，
> 属于安全策略而非能力缺失。

### 4. 语音车控与座舱服务（官方与发布会口径）

| 类别 | 能力 |
| --- | --- |
| **语音车控** | 超 **80%** 电子电气硬件支持语音控制：座椅、车窗、后视镜、氛围灯、后备箱等，支持**口语化说法** |
| **大模型问答** | 盘古 + DeepSeek 双模型融合，"快慢思考"自适应；用车知识解答、百科问答 |
| **沿途服务** | "**一路聊**"：基于实时地理位置识别沿途景点、建筑并解答 |
| **娱乐资讯** | 小艺搜歌（按歌词 / 背景信息找歌）、**小艺频道**（实时资讯播报 + 追问） |
| **车载智能体** | 美团（订餐）、喜马拉雅（播客）、口语练习生（英语陪练） |
| **个性化** | 小艺习惯推荐（学习习惯后自动执行）、个性化记忆 |
| **方言** | 支持 **10 种**（后期升级至 **16 种**）方言自由对话，**无需切换设置** |
| **语音播报** | 真人度达 **97%** |

**发展节点**：车载版本 2021 年 3 月启动开发；2024 年 6 月升级为系统级智能体；
2024 年 10 月起大模型车载小艺陆续 OTA 上车鸿蒙智行全系车型。

## 二、腕上小艺：手表端能力

### WATCH 6 系列"腕上小艺"

| 能力 | 说明 |
| --- | --- |
| 健康指标解读 | 基于手表健康数据提供解读与建议 |
| 腕上控家 | 在手表上控制智能家居设备 |
| 实时翻译 | 手表端实时翻译能力 |
| 语音交互 | 翻腕亮屏即可唤醒（多设备协同中的"焦点设备优先"） |

### 手表在协同唤醒中的地位

- **焦点设备优先**规则中，**手表翻腕亮屏**优先级最高（优先于耳机佩戴、手机亮屏）；
- 默认设备排序中手表位于末位（有屏音箱 > 无屏音箱 > 智慧屏 > 车机 > 手机 > 平板 > 手表）——即"就近与正在使用的设备优先"。

## 三、多设备任务流转示例

| 场景 | 流转方式 |
| --- | --- |
| 开车时记录事项 | 车机小艺应答 → 手机备忘录记录 |
| 车载摄像头抓拍 | 回家后在智慧屏上查看照片 |
| 运动时提醒 | 手表小艺提醒心率异常 |
| 手机任务上车 | 导航、音乐、会议自动接续到车机 |

## 四、协同唤醒规则（与车机/手表相关部分）

当多台设备同时听到"小艺小艺"：

1. **焦点设备优先**：手表翻腕亮屏 > 耳机佩戴中 > 手机亮屏 5 秒内；
2. **跨设备场景**：服务中的设备优先；默认排序 *有屏音箱 > 无屏音箱 > 智慧屏 > 车机 > 手机 > 平板 > 手表*；
3. **同类设备**：比较声强与声纹置信度。

也支持**语音指定设备名称**（如"用手机的小艺…"）。

## 五、常见问题

| 问题 | 解答 |
| --- | --- |
| 车机上的小艺和手机一样吗？ | 共享能力底座，车载版针对座舱场景强化（多音区、车控、流转） |
| 手表能独立使用小艺吗？ | WATCH 6 系列支持腕上小艺（健康解读、控家、翻译等） |
| 为什么车里喊小艺手机也响应？ | 协同唤醒按优先级选设备；可关闭部分设备的语音唤醒 |
| 车载小艺支持方言吗？ | 支持"方言自由说"（车载"新大脑"升级后），官方口径 10 种起、后续升级至 16 种 |
| 副驾能语音改驾驶设置吗？ | 不能，**驾驶相关设置仅主驾可语音操控**（官方安全策略） |
| 说"打开车窗"开的是哪个窗？ | 默认按**音区定位**执行该音区对应的车窗，主驾说就开主驾窗 |
| 车里怎么唤醒小艺？ | ① 说"小艺小艺"；② 按**方向盘右侧按键** |
| 老车型能用上这些功能吗？ | 多音区能力对应 HarmonyOS 4.0/4.2/4.3 鸿蒙智行车型；大模型能力自 2024-10 起 OTA 推送 |
