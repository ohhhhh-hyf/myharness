# 小艺的模型矩阵与选用指南

> 小艺不是"单一模型"，而是**多模型协同**：盘古做系统底座、DeepSeek 等第三方模型补深度思考、
> 端侧模型承担离线与隐私敏感任务。理解这张矩阵，才能判断"某个能力为什么强/为什么必须联网"。

## 一、模型矩阵总览

| 模型 | 角色 | 典型落地 |
| --- | --- | --- |
| **盘古大模型**（含盘古 5.0 / 6.0 内核） | 系统底座；能力与意图理解的基础 | 系统级智能体、端云协同、端侧能力 |
| **DeepSeek**（R1 → V4） | 深度思考、代码、数学、逻辑推理 | 智能体广场的 DeepSeek-R1 智能体；小艺 Claw 接入 DeepSeek V4 |
| **端侧 30B-A2B MoE**（原生盘古） | 离线与隐私敏感任务 | 麒麟 9050 Pro：断网整理相册、AI 图库整理 |
| **openPangu 2.0 系列**（2026-06 开源） | 面向开发者的开放模型族 | Pro：505B 总参 / 18B 激活（DSA+SWA 分层混合架构）；Flash：92B 总参 / 6B 激活、512K 上下文 |

## 二、端侧模型：为什么"断网也能用"

**硬件基础**：麒麟 9050 Pro（达芬奇架构 NPU）支持多尺寸大模型端侧运行与多级缓存协同优化，
为**行业首个实现总参数 30B、激活参数 2B（30B-A2B）端侧 MoE 全模态大模型运行**的移动平台。

**工程手段**（官方口径）：

- MoE 架构（只激活部分专家，算力可控）；
- 量化剪枝：推理速度提升 **50%**、内存占用减少 **20%**、专家切换频率降低 **50%**；
- 推理加速与内存优化协同。

**典型场景**：飞行模式下整理本地相册、图库一句话分类建册、离线文档总结/语音转写/影像修图
（HarmonyOS 7 起，端侧 AI 直接运行在本地 NPU，隐私数据不出设备）。

## 三、"万能插座"：模型如何被调度

- **接入架构**：鸿蒙侧采用"万能插座"式灵活接入，可对接盘古、DeepSeek 等业界优质大模型；
- **快慢自适应**（HDC 2026 双循环架构）：简单任务走快通道（低时延），复杂任务走慢思考（深度推理）；
- **端云协同**：端侧负责唤醒、隐私敏感与低时延任务；云侧负责大规模知识与复杂生成；
- **算力基础**：DeepSeek 等云侧模型推理基于**昇腾算力**（联合华为云与硅基流动推理加速）。

## 四、用户视角：怎么"选模型"

| 你的目标 | 建议路径 |
| --- | --- |
| 日常问答、系统控制、办公辅助 | 直接用主对话（盘古底座 + 快通道） |
| 复杂推理、代码、数学（要"深思熟虑"） | 说"打开 DeepSeek"使用 DeepSeek-R1 智能体（可开联网搜索） |
| 离线 / 隐私敏感（不想数据上云） | 端侧能力（30B-A2B MoE）+ 本地 AI 能力开关 |
| 超长上下文分析、自进化记忆 | 小艺 Claw（接入 DeepSeek V4，百万级上下文；需 HarmonyOS 6+） |
| 开发者做智能体 | 小艺开放平台选 LLM / 工作流 / A2A 模式（见《小艺开放平台与智能体广场生态》） |

## 五、模型选用的"判断口诀"

1. **要隐私 → 走端侧**（离线可用、数据不出设备）；
2. **要深度 → 走 DeepSeek 智能体**（展示思考过程、可联网）；
3. **要顺手 → 走主对话**（系统级调度、跨应用执行）；
4. **要开发 → 走开放平台**（LLM/工作流/A2A 三模式，插件可 MCP 接入）。

## 六、常见问题

| 问题 | 解答 |
| --- | --- |
| 小艺默认用哪个模型？ | 不对外单一指定：系统底座为盘古，按任务类型在端/云、快/慢之间调度 |
| 为什么有的回答"想很久"？ | 走的是推理模型（如 DeepSeek-R1），思考链会展示 |
| 端侧 30B 是什么概念？ | 总参数 30B、激活 2B 的 MoE，端侧全模态运行（麒麟 9050 Pro 首发） |
| 开发者能用盘古吗？ | 可以：openPangu 2.0 已开源（含预训练/后训练代码与训推算子，官方称业界首个） |
| 模型会换吗？ | 会，且是常态："万能插座"架构的价值就是模型可替换、能力持续升级 |
