# 小艺简报与信息聚合

> 小艺简报把"你今天要关心的事"聚合成一张桌面卡片：待办、通知、日程、天气、睡眠、
> 回忆、播客——一次看完，还能**一键语音播报**。它是"被动服务"里覆盖面最广的一项。

## 一、能力定位

| 维度 | 说明 |
| --- | --- |
| 技术基础 | **情景感知** + **个人 AI 知识图谱** |
| 生成时机 | 每天早上 **6:00 至当天 24:00** 期间 |
| 呈现形态 | 桌面自动生成并推送的**个人专属简报** |
| 交互方式 | 一站式聚合关键信息，支持**一键语音播报** |
| 场景定位 | 官方称围绕**效率工具、情感健康、学习发展**三大场景推荐，充当"智能信息官" |

## 二、简报包含哪些模块

| 模块 | 内容 |
| --- | --- |
| **全局待办** | 整合系统及各应用待办事项，统一呈现 |
| **通知摘要** | 梳理 App 通知、提炼核心内容，**推送时间可自定义** |
| **日程简报** | 展示最近日程安排，并**标识冲突日程** |
| **重要日** | 重要日来临前提醒 |
| **天气简报** | 实时天气与个性化生活建议（异常预警、穿衣指南等） |
| **睡眠简报** | AI 睡眠分析与建议（**需佩戴华为手表 / 手环**） |
| **时光回忆** | 那年今日、AI 游记等 |
| **每日播客** | 根据兴趣偏好**每日定期更新**资讯播客 |

> "日程冲突标识"和"通知摘要"是实用度最高的两项：前者把"三件事撞车"提前暴露，
> 后者把几十条推送压成几句话。

## 三、首发与版本

| 时间 | 事件 |
| --- | --- |
| 2025-11 | 向 Mate 80 系列推送 HarmonyOS 6.0.0.115 SP8，**首次带来小艺简报** |
| 后续 | 老机型回归：Mate 70 系列、Mate 60 系列等陆续放开可用（此前曾一度下线） |

**支持机型**（部分）：Pura 80 / Pura 90 系列、Mate 80 / 70 / 60 系列、Mate X6 / X7 系列、
nova 15 / nova 16 系列、Pura X Max 等。
**适用系统**：HarmonyOS 6.0 / 6.1。

## 四、怎么开启

1. 在桌面**添加 2×2 或 2×4 的"小艺建议"卡片**；
2. 进入 **设置 > 小艺 > 小艺建议 > 管理卡片 > 简报开关**，可分别开关各简报模块、
   设置摘要推送时间。

## 五、怎么关闭（分层控制）

| 想关掉的范围 | 操作 |
| --- | --- |
| **整个简报** | 长按简报卡片 > "不再推荐此卡片" |
| **单个模块** | 设置 > 小艺 > 小艺建议 > 管理卡片 > 简报开关，逐个关闭 |
| **只调推送时间** | 同上路径，在"通知摘要"中自定义推送时间 |

> 这种"整体 / 模块"两级控制比一刀切更实用：常见做法是保留待办与日程，
> 关掉推送类模块。

## 七、使用建议与边界

**建议：**

1. 先只开**待办 + 日程 + 天气**三项，体验一周后再决定是否加通知摘要；
2. **通知摘要的推送时间**建议设为起床后或通勤前，避免夜间打扰；
3. 睡眠简报需要**长期佩戴手表/手环**才有意义，偶尔戴几次数据参考价值低。

**边界：**

- 有**机型与系统版本门槛**（HarmonyOS 6.0 / 6.1 且限机型列表）；
- 睡眠简报**依赖穿戴设备**，无手表 / 手环时该模块无数据；
- 「时光回忆」「每日播客」等属内容推荐类，**可单独关闭**；
- 简报聚合了通知与日程等敏感信息，锁屏可见性需按自己的场景评估（隐私控制见《小艺的记忆与隐私实操》）。

## 八、常见问题

| 问题 | 解答 |
| --- | --- |
| 为什么桌面没有简报？ | 需要**手动添加小艺建议卡片**（2×2 或 2×4），不会自动出现 |
| 可以只要待办、不要播客吗？ | 可以，在"管理卡片 > 简报开关"里逐项关闭 |
| 通知摘要会读我的私密通知吗？ | 会聚合 App 通知，建议按需开启并评估锁屏可见性 |
| 睡眠简报没数据？ | 需**佩戴华为手表 / 手环**采集 |
| 老机型能用吗？ | Mate 70 / Mate 60 系列等已陆续放开，具体以版本推送为准 |
| 觉得打扰怎么彻底关掉？ | 长按简报卡片 >"不再推荐此卡片" |
