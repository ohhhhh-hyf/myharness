# 隐私安全设计与开发者激励

> 小艺的隐私设计强调"**端侧优先 + 数据最小化 + 透明可控**"：唤醒词与声纹本地处理，
> 上云数据即用即删；在 Agent 时代还通过了国家级安全专项评测。

## 一、数据处理原则

### 1. 官方隐私设计五原则

- 数据最小化；
- 数据端侧处理；
- 透明可控；
- 身份保护；
- 数据安全保障。

### 2. 端侧 vs 云侧

| 处理位置 | 典型场景 |
| --- | --- |
| **端侧处理** | 打开应用、拨打电话、通话摘要等意图；唤醒词、声纹等生物特征**全部留在本地**；部分视觉能力（如端侧人像识别） |
| **上云处理** | 资讯助手、知识问答、内容创作等复杂任务（云侧大模型算力更强，体验更流畅） |

### 3. 上云数据的承诺

- 数据**仅用于小艺对话服务**，**即用即删**，绝不对外共享或滥用；
- 提供**本地 AI 能力**开关（本地文本润色、本地文档摘要问答等）：开启后即使联网也不会上传数据；
- 鸿蒙电脑支持**本地模型离线问答**，适合数据安全要求高的用户。

### 4. 模式与授权

- **基本模式**：仅本地读取图片、应用列表、短信、日程、联系人，用于本机搜索与建议；
- **全量模式**：解锁跨应用与高阶能力（同时意味着更多数据与权限参与）；
- 唤醒词、声纹等生物特征不上传；
- 《关于小艺与隐私的声明》与《小艺收集个人信息明示清单》公开可查（列出各功能收集目的、信息类型与字段）。

## 二、Agent 时代的安全新要求

### 1. 小艺 Claw 的安全认证

- **2026-04**：小艺 Claw 通过**中国信通院**终端厂商 Claw 类智能体**安全专项评测**；
- 成为国内**首个国家级认证的 Claw 类智能体**；
- 覆盖八个维度：用户级安全沙箱、提示词注入防护、精细化权限控制、端到端数据保护等。

### 2. 行业测评观察（复旦白泽团队）

- 华为小艺**视觉处理能力突出**：端侧算法能精准识别并移除背景人像；
- 行业共性问题：AI 智能体申请的权限数量多（部分超过 100 项），涉及读屏（`READ_FRAME_BUFFER`）、模拟点击（`INJECT_EVENTS`）等高敏权限——这是所有手机智能体的通用挑战，需持续治理。

### 3. 端侧模型与离线能力

- HarmonyOS 7 的**端侧 30B MoE 大模型**：无网状态可完成图库整理等复杂任务；
- 端侧 Agent（小艺任务）本地运行，更安全、更稳定。

## 三、用户可执行的隐私操作

| 目的 | 操作 |
| --- | --- |
| 数据不上云 | 开启"本地 AI 能力"；鸿蒙电脑可用本地模型离线问答 |
| 减少数据采集 | 使用基本模式；关闭个性化推荐与改进计划 |
| 管理敏感信息 | 小艺帮记身份验证（指纹/人脸/锁屏密码）；房间锁等家庭管控 |
| 查看数据规则 | 阅读隐私声明与个人信息明示清单；设置中查看权限列表 |
| 问题反馈 | 反馈时勾选共享日志（便于定位，注意日志范围） |

## 四、开发者激励与生态（配套阅读）

- **小艺开放平台**：开发、调试、上架、分发全链路（详见《小艺开放平台与智能体广场生态》）；
- **天工计划**：10 亿元投入；单智能体最高 75 万元、单开发者累计最高 200 万元；需在 2026-10-31 前完成开发并上架；
- **变现**：集成华为 IAP 收银台，支持付费技能、订阅、内购。

## 五、常见问题

| 问题 | 解答 |
| --- | --- |
| 小艺会把我的语音上传吗？ | 唤醒与声纹在本地完成；唤醒后的对话按功能需要处理，云侧数据即用即删 |
| 关掉联网还能用吗？ | 部分端侧能力可用（唤醒、基础指令、端侧模型任务） |
| 智能体权限太多安全吗？ | 平台侧有安全评测与权限治理机制；用户可在设置中审查与关闭权限 |
| 数据能删除吗？ | 通过隐私设置管理；具体删除路径以《隐私声明》与系统设置为准 |
| 企业数据能用吗？ | 建议使用本地 AI/本地模型与基本模式，并遵循企业合规要求 |
