# 小艺功能版本门槛与升级速查

> "别人有这个功能，我为什么没有？"——多数情况是**系统版本 / 小艺 App 版本 / 机型**
> 三重门槛之一未满足。本文把已知门槛集中成表，便于逐项核对。

## 一、总表（按功能）

| 功能 | 最低系统版本 | 其他要求 |
| --- | --- | --- |
| 小艺私语 | HarmonyOS 5.0+ | 支持 Mate 70/80、Pura X/80 等机型 |
| 小艺字幕 | HarmonyOS 5.0+ | 通话场景字幕在 5.0 下线；6.0.0.328 SP22 起恢复控制中心入口 |
| 小艺翻译 | HarmonyOS 5.0+ | 部分能力平板/手机通用 |
| 小艺通话 / 帮接 / 摘要 | HarmonyOS 5.0+ | 摘要要求通话 100 字以上、2 小时以内 |
| 小艺帮记 | HarmonyOS 5.1+ | 小艺 App 11.5.2.300+ |
| 小艺慧记 | HarmonyOS 6.0+ | 2025-05 鸿蒙电脑首发，逐步适配手机/平板 |
| 小艺修图 | HarmonyOS 6.0+ | 小艺 App 11.3.9.320+；部分功能需 6.1 / 7.0 |
| 小艺 Claw | HarmonyOS 6+ | 小艺 App 对应版本；接入 DeepSeek V4 |
| 耳机 AI 键（帮接/摘要） | HarmonyOS 6.1+ | FreeBuds Pro 5 / FreeClip 2 等型号 |
| 端侧 30B 大模型能力 | HarmonyOS 7 | 麒麟 9050 Pro（Mate XT2 首发） |
| 小艺任务（端侧 Agent） | HarmonyOS 7 | 系统级端侧 Agent |
| 对话式文档编辑 | HarmonyOS 7 | Mate XT2 大屏专属 |
| DeepSeek-R1 智能体 | HarmonyOS 5.0.0.130+ | 小艺 App 11.2.10.340+（平板 11.2.10.341+） |
| 小艺看世界（手机） | HarmonyOS 5.0+ | 多款 Mate/Pura/nova 机型 |
| 声音修复 / 听觉辅助 | HarmonyOS 6.0/6.1+ | Mate 80、Pura 90 等机型 |
| 小艺管家 6.0（智能家居） | 按鸿蒙智家版本 | 2026-04 起分批推送 |

## 二、三类"找不到功能"的原因与处理

| 原因 | 表现 | 处理 |
| --- | --- | --- |
| 系统版本不够 | 设置里没有对应入口 | 升级系统（设置 > 系统和更新） |
| 小艺 App 版本不够 | 功能在但不可用/入口缺失 | 应用市场升级"小艺"App |
| 机型未适配 | 同版本但该机型暂不支持 | 等待适配；关注官方支持页的机型列表 |

## 三、升级注意事项

1. **升级后检查设置**：语音唤醒、连续对话、后台权限等可能恢复默认关闭（这是"升级后小艺变笨"的常见原因）；
2. **跨大版本升级**：如 HarmonyOS 4 → 5 前需将智慧语音升级到 12.1.8.410 及以上，否则要重新开关并录入唤醒词；
3. **新功能分批推送**：同一版本、同一机型也可能分批到达；
4. **模式影响能力**：基本模式会禁用高阶 AI 能力，检查"应用服务模式"是否为全量模式。

## 四、快速自检清单

- [ ] 系统 = 目标功能要求的最低版本以上？
- [ ] 小艺 App 是应用市场最新版？
- [ ] 应用服务模式 = 全量模式？
- [ ] 语音唤醒已开启、唤醒词已录入（仅普通话）？
- [ ] 该机型在官方支持页的"适用机型"列表内？

## 五、常见问题

| 问题 | 解答 |
| --- | --- |
| 为什么同一功能有人能用我不能？ | 三重门槛 + 分批推送；以官方支持页适用机型为准 |
| 升级后要重录唤醒词吗？ | 跨大版本升级有时需要（见上文第 2 条） |
| 小艺 App 在哪升级？ | 华为应用市场搜索"小艺" |
| 老机型还能用新能力吗？ | 端侧大模型能力与芯片强相关（如麒麟 9050 Pro）；云侧能力门槛相对低 |
| 哪里查最准的门槛？ | 华为消费者业务官网支持中心搜索对应功能名 |
