# 小艺在鸿蒙电脑与平板上的能力

> 手机以外，小艺最完整的第二主场是**鸿蒙电脑**。这里的定位不是"语音助手"，
> 而是**系统级智能助理 + 端侧 Agent**：从文档撰写、资料检索一直到替你操作文件系统。

## 一、时间线：从"能说话"到"能干活"

| 时间 | 里程碑 |
| --- | --- |
| 2025-05-08 | 鸿蒙电脑首次亮相（HarmonyOS 5），"华为智慧办公"升级为**鸿蒙办公**，小艺成为系统级智能助理 |
| 2026-04 | **小艺 Claw** 在 MateBook 鸿蒙电脑开启首批付费 Beta，实现手机 / 平板 / 电脑**三端全覆盖** |
| 2026-09 | HarmonyOS 7 **小艺任务**上线：端到端完成任务的本地端侧 Agent |

## 二、鸿蒙电脑首发的四项核心能力

| 能力 | 说明 |
| --- | --- |
| **小艺文档助理** | 一句话完成 PPT 创作（需 WPS 协同） |
| **小艺知识空间** | 从本机全盘文档中检索信息，直接给出答案和总结（详见《小艺知识空间与联网搜索》） |
| **小艺慧记** | 会议纪要转写、摘要总结、会议托管跨端提醒 |
| **小艺设备专家** | 一句话完成屏幕亮度调节、截屏、录屏等电脑设置 |

> 注意"设备专家"这一项：它体现的是**系统级权限**——小艺能直接操作系统设置，
> 而不只是"教你怎么点"。

## 三、HarmonyOS 7：小艺任务（端侧 Agent）

HarmonyOS 7 中，小艺任务被定位为"**端到端完成任务**"的一站式办公助手，**运行在本地端侧**。

**文件与桌面管理**：

- 智能语义分类桌面文件（按内容而非文件名归类）；
- 批量重命名、重复文件清理；
- **语义回滚**（按语义撤销之前的批量操作）。

**内容生成与填表**：

- 一键生成**日报 / 周报**；
- 自动填写线上表单和网申信息。

**远程操控电脑**（跨设备）：

- 手机与 PC **同账号登录**即可远程调用；
- **合盖待机也能用**：让小艺找文件、翻译文档、提炼摘要、生成思维导图。

**可调用的能力规模**：超 **2100 项**系统能力、**2000+** 鸿蒙智能体、**500+** 伙伴精选 Skills。

## 四、平板上的小艺

- 小艺 Claw 已覆盖平板（与手机、电脑同一账号通用，跨设备管理日程、备忘录）；
- 平板作为"中间形态"，既能承接手机的伴随式服务，也能承担电脑侧的轻办公任务；
- 配合鸿蒙分布式能力，可参与三设备键鼠共享与内容流转（见下）。

## 五、跨设备协同：电脑作为中枢

| 能力 | 说明 |
| --- | --- |
| **三设备键鼠共享** | 手机、电脑、平板之间无缝切换同一套键鼠 |
| **手眼同行 / 跨设备互通** | 手机、平板到电脑的内容无缝衔接 |
| **应用接续** | 换设备继续未完成的应用任务 |
| **华为分享** | 设备间文件快速传输 |
| **碰一碰** | 手机轻触电脑屏幕，图片直接插入**指定窗口位置**；支持 Workbuddy 文件双向流转、Wi-Fi 免密连接 |

## 六、生态适配现状

- 鸿蒙电脑已覆盖通用办公、影音娱乐、实用工具等高频场景；
- **WPS Office** 深度集成小艺 AI，实现 PPT 一键生成；
- 飞书、中望 CAD、剪映等应用已完成适配。

## 七、使用建议与边界

**建议：**

1. 首次使用先在**小艺知识空间**里确认检索范围覆盖了你关心的目录；
2. 需要跨端远程操控时，确保手机与电脑**登录同一账号**；
3. 用 Claw / 小艺任务做批量文件操作前，先在小范围试用"语义回滚"是否可接受。

**边界：**

- "小艺文档助理"生成 PPT **依赖 WPS 协同**，未安装 WPS 时能力受限；
- 端侧 Agent（小艺任务）**有芯片与机型门槛**，老机型可能不可用（见《端侧 AI 的硬件门槛与功耗》）；
- 远程操控、跨端文件访问需**同账号 + 授权**，涉及隐私数据时的控制方式见《小艺的记忆与隐私实操》。

## 八、常见问题

| 问题 | 解答 |
| --- | --- |
| 鸿蒙电脑上的小艺和手机上是同一个吗？ | 是同一账号体系下的同一助手，但**能力集不同**（电脑侧强在文档、检索、文件操作） |
| 小艺能直接改我电脑的设置吗？ | 能，"小艺设备专家"可一句话完成亮度、截屏、录屏等操作 |
| 手机能远程操作电脑吗？ | 可以，需**同账号登录**；HarmonyOS 7 起支持合盖待机状态下查找文件、翻译、提炼摘要 |
| 生成 PPT 需要什么前提？ | **WPS Office** 协同 |
| 平板支持 Claw 吗？ | 支持，且与手机、电脑**同一账号通用** |
