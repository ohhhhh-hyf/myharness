# 能力全景与小艺能做什么

> 小艺的能力可分为六类：系统控制、信息查询与生活服务、内容创作与办公、会议与通话辅助、
> 多模态与影像、跨应用任务执行。以下是分类清单与常用指令示例。

## 一、系统控制（一句话开关）

**基础开关**：打开/关闭蓝牙、Wi-Fi、移动网络、个人热点、飞行模式、NFC、深色模式、护眼模式、省电模式、静音模式、旋转锁定；亮度/音量调节；关机、重启、关闭应用。

**实用隐藏技巧**：

| 说什么 | 效果 |
| --- | --- |
| "你在哪里" | 手机最大音量响铃 + 闪光灯闪烁，方便找手机 |
| "清理后台，手机加速" | 一键释放运存 |
| "截取长截图" | 自动滚动拼接长图 |
| "朗读屏幕文字" | 网页、文章全程语音播报 |
| "清理扬声器灰尘" | 播放高低频声波震动清灰（**注意：部分网络流传口令已失效或下线**） |

## 二、信息查询与生活服务

- **查询类**：天气、快递物流、今日油价、限行尾号、垃圾分类、百科问答、算术、翻译句子；
- **出行类**：查路线、查公交地铁时刻表、记住停车位、帮我找车、打车、订机票；
- **提醒类**：设置闹钟、倒计时、日程提醒、每月交话费提醒；
- **生活类**：发消息、转账、充话费、播放音乐/视频（"播放周杰伦的歌""下一首"）。

## 三、内容创作与办公（详见《小艺帮写与办公创作》）

- **小艺帮写**：文案润色改写、录音转文本、摘要、排版、思维导图；
- **小艺文档助理**：文档摘要/问答/比对、Word/Excel/PPT 生成、格式转换；
- **小艺深度研究**：跨格式解析文本、图像与 PDF，输出带引用的结构化研究报告；
- **小艺深度解题**：拍照解题、批改作业、收录错题。

## 四、会议与通话辅助（详见对应专题文档）

- **小艺慧记**：会议实时转写、发言人区分、纪要生成、待办提取；
- **小艺通话**：代接来电（小艺帮接）、通话实时转文字、通话摘要、声音修复；
- **小艺字幕**：视频/麦克风声音实时转字幕（中英日韩）；
- **小艺翻译**：文本、面对面、同声传译、文档、连续翻译（支持 20 种语言）。

## 五、多模态与影像

- **小艺修图**：一句话修图、AI 消除路人、老照片修复、AI 扩图；
- **屏幕可见可问**：屏幕上有地址可问"导航到这"，有电话可说"拨打这个号码"；
- **拖入小艺执行**：把图片/文件拖到屏幕底部导航条，可提取表格/文字/生成摘要；
- **小艺看世界**：配合华为 AI 眼镜，为视障用户提供视觉信息语音化。

## 六、跨应用任务执行（高阶能力）

- **小艺帮帮忙**：跨应用自动完成任务，如"帮我在京东再来一单最近买的可乐"；
- **多指令一次执行**：如"打开静音模式、关闭移动数据、把亮度调到最低"；
- **场景自动化**：如"每天晚上 23 点自动开启静音、关闭 WiFi、调低亮度"；
- **可见即可说**：直接念页面按钮名称即可操作 App；
- **小艺任务**（HarmonyOS 7 端侧 Agent）：文件整理、批量重命名、日报周报生成、智能填表等。

## 七、使用前提与建议

1. **开启语音唤醒**：设置 > 小艺 > 唤醒与对话 > 语音唤醒；
2. **切换全量模式**：小艺 App → 设置 → 应用服务模式 → **全量模式**，解锁跨应用操作、"帮帮忙"等高阶能力；
3. **开启连续对话**：一次唤醒连续下达多条指令（默认可能关闭，建议手动开启）；
4. **锁屏语音技能**：可在设置中允许锁屏时使用语音技能。

## 八、能力边界（做不了什么）

- 纯文字生成类任务（如"帮我写周报"）在部分版本上能力有限，更多依赖"小艺帮写/文档助理"等专门入口；
- 上下文指代消解较弱（如"再播放刚才那首歌"后续指令可能误判）；
- 跨应用任务链受第三方 SDK 权限与账户适配限制；
- 方言识别覆盖约 10 种，但准确率不稳定，且**不支持方言语音播报**；
- 跨应用读取通讯录关系链默认禁止，需额外声明授权。
