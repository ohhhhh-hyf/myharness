# 小艺智能体广场与代表智能体

> 智能体广场是小艺的"应用商店"：第三方与官方的智能体在此上架，通过语音、小艺搜索、
> 小艺建议、系统导航条等入口触达用户。截至 2026-06，累计上架 **2000+** 鸿蒙智能体。

## 一、三个入口（以 DeepSeek-R1 为例，官方 FAQ）

| 入口 | 操作 |
| --- | --- |
| 智能体广场 | 小艺 App → 底部「**发现**」→「**智能体**」标签 → 找到目标智能体 → 点击打开 |
| 主对话指令 | 小艺 App「对话」页 → 发送"**打开DeepSeek**" |
| 语音唤醒 | 唤醒半屏态小艺 → 说"**打开DeepSeek**" |

**版本要求（DeepSeek-R1）**：HarmonyOS **5.0.0.130** 及以上；小艺 App **11.2.10.340** 及以上
（平板 11.2.10.341 及以上）；HarmonyOS 4.x 及以下不支持。

## 二、代表智能体一览

| 智能体 | 提供方 | 定位 |
| --- | --- | --- |
| **DeepSeek-R1** | DeepSeek | 深度思考、代码编写、数学计算、逻辑推理、文本生成；支持联网搜索开关 |
| **Kimi 系列**（塔罗师、爆款文案生成器） | 月之暗面 | 娱乐互动与内容创作类 |
| **讯飞晓医** | 科大讯飞 | 医疗健康问答 |
| **AiPPT.cn** | 第三方 | 一键生成演示文稿 |
| 首批 80+ 应用智能体（HarmonyOS 6 起） | 腾讯、阿里、美团、字节等 | 教育医疗、娱乐互动、生活服务（旅行规划、值机选座、点外卖等） |

## 三、DeepSeek-R1 使用要点

- **能力**：代码、数学、逻辑推理、文本生成；展示**完整思考过程**；
- **联网搜索**：正式版新增开关，可增强答复时效性；
- **交互**：支持语音输入、多种音色、长按分享生成内容；
- **技术底座**：基于**昇腾算力**，联合华为云与硅基流动进行推理加速；
- **限制**：需联网调用云端模型，弱网环境可能响应延迟；主对话仅支持直接打开 DeepSeek-R1，
  其他智能体需从广场进入。

## 四、智能体从哪来（一句话了解生态）

智能体由开发者通过**小艺开放平台**开发并上架：支持 LLM 模式、工作流模式、A2A 模式；
可调用官方系统插件（天气、日历、地图、文件管理等）；上架后按用户需求与意图公平分发。
开发者激励见"天工计划"（10 亿元投入，单智能体最高 75 万元）。

## 五、常见问题

| 问题 | 解答 |
| --- | --- |
| 为什么广场里找不到某个智能体？ | 可能未上架/未适配当前系统版本；智能体按机型与版本分批可见 |
| 智能体能离线用吗？ | 广场智能体多为云侧 Agent（需联网）；端侧智能体能力见 HMAF 说明 |
| 用智能体要额外付费吗？ | 平台支持付费技能/订阅/内购等模式，具体以各智能体说明为准 |
| 智能体和"技能（Skill）"什么区别？ | 智能体是独立服务主体（可对话），Skill 是可被小艺调用的能力插件 |
| 如何让自己的智能体上架？ | 小艺开放平台注册 → 开发 → 真机调试 → 提交审核 → 广场分发 |
