# 小艺多端能力速查对照

> 同一句"小艺小艺"，在不同设备上唤醒的是**不同的能力集**。本文按设备形态归纳
> **入口方式、独有能力与前置条件**，方便快速判断"这件事该在哪台设备上做"。

## 一、总览对照表

| 设备 | 主要入口 | 标志性能力 | 关键前提 |
| --- | --- | --- | --- |
| **手机** | 语音 / 长按导航条 / 长按电源键 / 指关节圈选 | 小艺导航条、伴随式 AI、跨应用执行 | HarmonyOS 5.0+（伴随式需 6.1+） |
| **平板** | 同手机导航条 | 轻办公、跨设备流转 | 与手机同账号 |
| **鸿蒙电脑** | 系统级集成 | 文档助理、知识空间、设备专家、小艺任务 | 机型 + WPS（做 PPT） |
| **车机** | "小艺小艺" / 方向盘右侧按键 | 多音区识别、语音车控、一路聊 | 鸿蒙智行车型 |
| **耳机** | 手势 / 唤醒词（默认关闭） | 小艺帮接、通话摘要、按住说话 | 机型 + HarmonyOS 6.1（AI 键） |
| **AI 眼镜** | 长按镜腿 AI 键 1 秒 | 小艺看世界、识物、随身导游 | HarmonyOS 6.0.0.130+ |
| **手表** | 抬腕 / 按键 | 运动健康问答、腕上快捷操作 | 配套运动健康 App 版本 |
| **智慧屏** | 遥控器语音 | 大屏视觉交互、全屋控制 | MateTV 等机型 |

## 二、手机：入口最丰富的一环

**小艺导航条**（HarmonyOS 5 引入的常驻交互 UI）：

| 操作 | 作用 |
| --- | --- |
| **长按**导航条 | 在任意界面唤醒小艺 |
| **左右横滑** | 快速切换应用 |
| **点击** | 返回（需开启：设置 > 系统 > 系统导航 > 点击导航条返回） |
| **拖拽**文本 / 图片 / 文件到导航条 | 投喂给小艺做摘要、表格提取、图片翻译 |

**唤醒方式共四种**：① 语音"小艺小艺"；② 长按屏幕底部导航条（锁屏也可用）；
③ 长按电源键；④ 指关节圈选「问问小艺」。

**其他入口**：
- **伴随式 AI**：双击导航条（需先开启"双击导航条触发伴随式AI"，设置 > 系统 > 伴随式AI；HarmonyOS 6.1，Pura X Max 首发）；
- **小艺游戏面板**：长按导航条 / 长按电源键 0.5 秒 / 语音唤醒（小艺 App 11.3.1.300+）；
- **小艺看世界**：唤醒小艺后点击打电话图标打开摄像头（HarmonyOS 5.1+ 及指定机型）。

**导航条可关闭性**：导航条本身为系统功能不可关闭；可改用三键导航隐藏它，
也可在「设置 > 系统 > 系统导航 > 关闭长按触发小艺对话」中关闭唤醒（保留 UI）。

## 三、车机：多音区是核心差异

**多音区智慧感知**（官方支持文档，适用 HarmonyOS 4.0 / 4.2 / 4.3 的鸿蒙智行）：

| 能力 | 说明 |
| --- | --- |
| **多音区识别** | 利用多音区判定与防串扰技术，区分不同座椅用户的指令，互不干扰 |
| **音区定位** | 只说"打开车窗"即执行**主驾**车窗操作，无需说"主驾" |
| **权限控制** | 驾驶相关设置**仅主驾可语音操控**；非主驾音区可自主开关 |
| **唤醒方式** | ① 说"小艺小艺"；② **方向盘右侧按键** |

**车载小艺其他能力**：语音车控覆盖超 **80%** 电子电气硬件（座椅、车窗、后视镜、氛围灯、
后备箱等，支持口语化说法）；盘古 + DeepSeek 双模型"快慢思考"；"**一路聊**"基于实时地理
位置识别沿途景点并解答；小艺搜歌、小艺频道；美团 / 喜马拉雅 / 口语练习生等智能体；
方言自由对话（10 种起，后续升级至 16 种）；语音播报真人度达 97%。

## 四、耳机：从"听"到"办"

**唤醒**：手势控制 或 说出唤醒词"小艺小艺"——**两种方式默认关闭，需手动开启**。
适用 HarmonyOS / iOS / Android。

| 能力 | 支持型号 | 前提 |
| --- | --- | --- |
| 语音唤醒 | FreeBuds Pro 5、FreeClip 2 系列、FreeBuds 7i、FreeBuds 6、FreeBuds Pro 4、FreeClip、WATCH Buds 等 | 手动开启 |
| **按住说话 / 连续对话** | FreeBuds Pro 5、FreeClip 2 系列 | 连续对话约 **10 秒**内可连续追问 |
| **AI 键操控小艺智能体**（帮接、通话摘要） | FreeBuds Pro 5、FreeClip 2 系列 | 搭配 **HarmonyOS 6.1+** 华为设备 |

> 一个易被忽略的细节：AI 键连接**安卓 / iOS 设备时操控的是豆包智能体**，
> 只有连接 HarmonyOS 6.1+ 华为设备才走小艺。该 AI 键功能适用区域为**中国大陆**。

## 五、AI 眼镜：唯一的第一人称入口

详见《小艺在 AI 眼镜上的能力》。要点：

- 型号 **AIL-G01**，35.5g，1200 万摄像头，约 12 小时综合续航，2499 元起；
- **长按左镜腿 AI 快捷键 1 秒**进入小艺看世界；
- 支持识物、随身导游、穿搭建议、出国翻译，**支持插嘴打断**；
- 需 HarmonyOS 6.0.0.130 及以上部分华为手机。

## 六、手表与智慧屏

| 设备 | 能力 |
| --- | --- |
| **手表** | 腕上小艺、运动健康智能体（需手机运动健康 App 16.0.10.300+）、运动目标设置与数据问答 |
| **智慧屏** | MateTV 搭载小艺 Claw 与"小艺看世界"视觉交互，是客厅场景的入口与全屋控制终端 |

## 七、怎么选设备：一张判断表

| 你要做的事 | 最合适的设备 | 原因 |
| --- | --- | --- |
| 跨应用执行任务、拖拽文档分析 | **手机** | 导航条拖拽 + 跨应用权限 |
| 全盘文档检索、写 PPT、批量整理文件 | **鸿蒙电脑** | 系统级文件与文档能力 |
| 开车时控制车内设备 | **车机** | 多音区识别，驾驶相关仅主驾可操作 |
| 骑车 / 双手占用时问路识物 | **AI 眼镜** | 免手持 + 第一人称视觉 |
| 通话中自动接听、生成摘要 | **耳机** | AI 键直达帮接与摘要 |
| 运动数据问答、健康提醒 | **手表** | 唯一有身体数据的设备 |
| 全屋设备语音控制 | **智慧屏 / 眼镜** | 家庭场景常驻入口 |

## 八、通用注意事项

1. **同账号是关键**：跨设备流转、远程操控、三端通用都以同一华为账号为前提；
2. **默认关闭项需手动开**：耳机唤醒、耳机 AI 键相关能力、伴随式 AI 都不是默认开启；
3. **版本门槛各不相同**：手机/耳机/眼镜/电脑的门槛互不相同，不要用一台设备的版本推断另一台
   （详见《小艺功能版本门槛与升级速查》）；
4. **能力受硬件限制**：老机型或中端芯片可能不支持端侧 AI 能力（见《端侧 AI 的硬件门槛与功耗》）。

## 九、常见问题

| 问题 | 解答 |
| --- | --- |
| 手机上的小艺和车机上的是同一个吗？ | 同一账号体系下的同一助手，但**能力集按设备裁剪** |
| 耳机为什么喊不出来小艺？ | 语音唤醒**默认关闭**，需在 App 中手动开启 |
| 眼镜能脱离手机使用吗？ | 不能，需搭配 HarmonyOS 6.0.0.130+ 的部分华为手机 |
| 车机上副驾能改驾驶设置吗？ | 不能，驾驶相关设置**仅主驾可语音操控** |
| 平板支持所有手机功能吗？ | 大部分可用，但依赖硬件的（如蜂窝通话相关）不适用 |
