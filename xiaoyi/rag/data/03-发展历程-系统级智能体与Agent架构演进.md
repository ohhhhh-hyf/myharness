# 系统级智能体与 Agent 架构演进（2025-2026）

> 2025 年小艺接入 DeepSeek、发布鸿蒙智能体框架（HMAF）与小艺开放平台；
> 2026 年鸿蒙系统向 **Agent 架构全面演进**，小艺以"意图即服务"为核心范式，成为全场景智慧分发入口。

## 一、2025：大模型协同 + 开放生态

### 1. 接入 DeepSeek（2025 年 2 月）

| 时间 | 事件 |
| --- | --- |
| 2025-02-05 | 基于原生鸿蒙的小艺 App 接入 **DeepSeek**，智能体广场上架 **DeepSeek-R1（Beta）** |
| 2025-02-09 | DeepSeek-R1 升级正式版，新增**联网搜索** |

- 技术路径：DeepSeek 模型推理基于**昇腾算力**，联合华为云与硅基流动进行推理加速；
- 能力变化：在**盘古与 DeepSeek 协同**下，小艺从"指令任务式"升级为"对话思考式"；
- 使用入口（HarmonyOS 5.0+）：小艺 App → 发现 → 智能体 → DeepSeek-R1，或直接说"打开 DeepSeek"。

### 2. HDC 2025：HMAF 与小艺智能体开放平台

- 发布**鸿蒙智能体框架（HMAF）**及白皮书《Agent 时代，鸿蒙应用生而智能》；
- **小艺智能体开放平台**上线，支持 LLM、工作流、A2A 等多种开发模式，可一键调用 50+ 系统插件；
- 启动"**天工计划**"：投入 10 亿元资金与资源，目标孵化超 1 万个 AI 原生元服务、1 千多种意图框架/MCP、5 千多个智能体。

## 二、2026：Agent 架构全面演进

### 1. 小艺能力的数据规模（HDC 2026）

| 指标 | 数据 |
| --- | --- |
| 日均唤醒 | 30 亿次 |
| DAU | 1.8 亿 |
| Agent 分发量 | 一年增长 4.5 倍 |
| 系统能力 Skill 化 | 2100+ 项 |
| 伙伴精选 Skills | 500+ |
| 上架鸿蒙智能体 | 2000+ |

### 2. 关键升级

- **HMAF 2.0**：提出"**意图即服务**"核心交互范式，升级 A2A、A2UI 协议；
- **双循环自演进架构**：外循环构建"快慢自适应 — 记忆自学习 — 执行自动化 — 反思自迭代"闭环；
- **长期记忆与上下文理解**：授权后可调用 200+ 项系统级数据（日程、文件、地点、睡眠、通勤偏好等）；
- **万能插座式模型接入**：可对接盘古、DeepSeek 等业界优质大模型；
- **开源盘古 openPangu 2.0**；
- **WATCH 6 系列"腕上小艺"**：健康指标解读、腕上控家、实时翻译。

### 3. 小艺 Claw：深度记忆与自进化

- 2026 年 4 月上线先锋版，支持**深度记忆和自我学习**，"越用越懂你"；
- 2026-04-29 更新引入**自进化能力**：记忆用户偏好、沉淀可复用技能；
- 接入 **DeepSeek V4**，实现百万级超长上下文；
- 需 HarmonyOS 6 及以上设备与小艺 App 对应版本；
- 通过中国信通院终端厂商 Claw 类智能体安全专项评测（详见安全文档）。

### 4. HarmonyOS 7：小艺任务与端侧 Agent（2026-09-07）

- **小艺任务**：系统级**端侧 Agent**，本地运行，可直接调用系统底层权限完成端到端任务；
- **对话式文档编辑**（Mate XT2 大屏）：语音/手写笔划词实现意图级编辑，全篇联动优化；
- **端侧 30B MoE 大模型**：无网状态下完成图库整理等复杂任务；
- **休眠态跨端办公**：手机小艺远程调取休眠/合盖 PC 文件并回传；
- **小艺自然聊**：嘈杂环境稳定唤醒、轻声耳语打断续聊。

## 三、演进主线总结

> 语音助手（2018）→ 智慧助手（2019）→ 大模型智慧助手（2023，盘古接入）
> → 系统级智能体（2024，Harmony Intelligence）→ Agent 生态核心入口（2025-2026，HMAF 与鸿蒙 AI）

三条主线：**盘古大模型 + 系统级融合 + 开放平台生态**。
