# 端侧 AI 的硬件门槛与功耗

> "断网也能用"不是软件功能，而是**芯片能力**。端侧大模型受算力、内存带宽、功耗与散热四重约束，
> 这决定了同一版本系统中，**不同机型能用的 AI 能力并不相同**。

## 一、为什么要有端侧模型

| 收益 | 说明 |
| --- | --- |
| **隐私** | 数据不出设备（相册整理、文档总结等敏感场景） |
| **时延** | 无需往返云端，交互更跟手 |
| **离线可用** | 飞行模式、弱网环境仍可完成部分任务 |
| **成本** | 减少云侧推理开销 |

代价是：端侧模型**必须为功耗与内存做大幅妥协**，能力上限低于云侧大模型。

## 二、承载端侧 AI 的芯片

| 芯片 | 端侧能力 | 关键指标 |
| --- | --- | --- |
| **麒麟 9050 Pro** | 行业首个端侧 **30B（300 亿参数）MoE 全模态**大模型运行平台，激活约 2B | 整机性能较上代 **+42%**；晶体管密度 **+55%** |
| **麒麟 9030 Pro**（Pura X Max） | 小艺"伴随式 AI" | 软硬芯云协同，更低功耗、更低时延 |
| **麒麟 9010S**（nova 15 Ultra） | NPU 协处理器负责**语音唤醒** | 唤醒延迟约 **790ms**；监听功耗仅 **2.3mW** |
| 麒麟 9040（Mate 90，**传闻未证实**） | 本地运行约 70 亿参数模型 | AI 算力约 68 TOPS |

> **准确性提示**：麒麟 9040 的一行来自未经官方确认的传言，仅作参考，不应作为选购依据。
> 其余三项有官方或发布会口径支撑。

## 三、功耗是怎么降下来的

端侧 AI 的最大障碍是**持续运行会吃空续航**。官方口径的工程手段：

| 手段 | 效果 |
| --- | --- |
| **逻辑折叠技术**（麒麟 9050 Pro 首发） | 分层排布芯片内部逻辑单元、增加垂直互联通道缩短信号传输路径，关键任务功耗最高**降低 66%** |
| **低功耗微内核 + 达芬奇架构 NPU** | 强调高能效，软硬芯云协同降低功耗与时延 |
| **休眠唤醒机制** | 端侧 AI 进程不被唤醒时**冻结挂起**，不持续占用算力；仅唤醒或点击触发时临时调用，任务结束快速释放 |
| **分级轻量化编译** | 按性能梯队适配：旗舰完整版 / 中端均衡版 / 老机型极简版 |
| **超空间内存技术** | 16GB 物理内存可达约 20GB 可用效果，保障端侧 AI 运行并兼顾续航 |

> 值得注意的是**分级轻量化编译**：它解释了为什么"同一个系统版本，不同机型 AI 能力不同"——
> 不是厂商有意阉割，而是强行在低算力芯片上加载大模型会导致耗电与卡顿失控。

## 四、能力门槛：哪些机型能用

| 层级 | 机型 | 可用能力 |
| --- | --- | --- |
| **完整** | 麒麟 9000 系列及以上（Mate 60 / 70、Pura X 系列等） | 完整端侧 AI 任务 |
| **受限** | nova 12 等中端机型 | 部分高阶 AI 特性不可用 |
| **老机型** | Mate 40 系列等 | 可升级系统，但高阶 AI 受限，提供"轻量模式"妥协流畅度 |

**典型端侧场景**（以 Mate XT2 为例）：断网状态下完成图库整理、相册一句话分类建册、
离线文档总结 / 语音转写 / 影像修图。

## 五、用户视角的实用结论

1. **买前看芯片，不只看系统版本**——功能可用性由芯片层级决定；
2. **"轻量模式"是取舍而非故障**——老机型上牺牲部分 AI 能力换取流畅与续航；
3. **担心耗电**可以观察设置中端侧 AI 相关开关（部分能力可关闭，改用云侧）；
4. **弱网/离线需求强**的用户，优先考虑支持 30B-A2B 端侧 MoE 的机型。

## 六、常见问题

| 问题 | 解答 |
| --- | --- |
| 为什么我的手机升级后没有某个 AI 功能？ | 多为**芯片算力门槛**限制，而非系统版本问题（对照见《小艺功能版本门槛与升级速查》） |
| 端侧 AI 会明显耗电吗？ | 有休眠挂起与分级编译等控制；具体表现因任务与机型而异 |
| 30B-A2B 是什么意思？ | 总参数 300 亿、**激活**约 20 亿的 MoE 结构：模型总量大，但单次推理只激活一小部分专家，算力可控 |
| 断网能用哪些功能？ | 相册整理、图库分类、离线文档总结 / 语音转写 / 影像修图等端侧任务 |
| 端侧和云侧哪个更强？ | 云侧更强；端侧胜在**隐私、时延、离线可用** |
| 未来会统一吗？ | 趋势是"端云协同"：端侧负责唤醒、隐私与低时延任务，云侧负责大规模知识与复杂生成 |
