# 小艺的记忆与隐私实操

> 记忆能力（帮记、长期记忆）建立在数据之上，因此"记忆怎么用"与"隐私怎么管"要一起看。
> 本文聚焦**可操作项**：模式切换、本地 AI、敏感信息验证、数据流向。

## 一、两种服务模式（官方隐私声明）

| 模式 | 数据范围 | 能力 |
| --- | --- | --- |
| **基本模式** | 仅本地读取图片、已安装应用列表、短信内容、日程、联系人 | 用于本机搜索与建议；**不提供**其他附加能力 |
| **全量模式** | 完整功能所需的授权与数据 | 跨应用操作、修图、会议转写、跨应用协作等高阶能力 |

**切换路径（官方口径）**：小艺 App >「我的」> 设置 >「**应用服务模式**」。

**找不到入口时排查**：是否登录华为账号、小艺 App 版本是否过旧、系统版本是否过低；
两个模式可随时切换，切回基本模式即恢复初始状态。

## 二、本地 AI 与端侧处理

| 能力 | 说明 |
| --- | --- |
| 本地 AI 能力开关 | 开启后**即使联网也不上传数据**（本地文本润色、本地文档摘要问答等） |
| 鸿蒙电脑本地模型 | 可离线问答，适合数据安全要求高的用户 |
| 端侧语音处理 | 唤醒词、声纹等生物特征**全部留在本地**；唤醒前不上传音频 |
| 端侧大模型 | HarmonyOS 7 的端侧 30B-A2B MoE：离线完成相册整理等任务，数据不出设备 |

> 注意：媒体口径提到部分机型端侧语音处理时延低至约 **500ms**，此类实测数值仅供参考，
> 以官方说明为准。

## 三、云侧数据的处理承诺

- 数据**仅用于小艺对话服务**，**即用即删**，不对外共享或滥用；
- 不想上云的功能可改用本地能力（见上）；
- 端侧可以完成的（打开应用、拨打电话、通话摘要意图）不上云；知识问答、资讯等复杂任务上云。

## 四、记忆相关的隐私控制

| 项目 | 控制方式 |
| --- | --- |
| 小艺帮记敏感信息 | HarmonyOS 6.1 起：查看身份证、银行卡等信息需**指纹/人脸或锁屏密码**验证 |
| 帮记数据存储 | TEE 可信执行环境，数据本地处理 |
| 记忆内容管理 | 在小艺帮记中查看/整理/删除；可关闭相关功能 |
| 个性化推荐 | 设置中可关闭个性化推荐与改进计划 |
| 权限审查 | 设置 > 应用 > 小艺 > 权限，逐项确认（麦克风、存储、位置等） |

## 五、实操建议（三步走）

1. **先定模式**：日常用全量模式；对隐私极敏感的场景切回基本模式；
2. **再定数据边界**：能本地的用本地（本地 AI / 端侧模型）；必须上云的知悉"即用即删"承诺；
3. **定期审查**：检查权限清单与智能体授权，关闭不再需要的项。

## 六、常见问题

| 问题 | 解答 |
| --- | --- |
| 小艺会一直偷听吗？ | 唤醒在本地完成，唤醒前不上传音频 |
| 基本模式会不会让功能变少？ | 会，跨应用、修图、会议转写等高阶能力需全量模式 |
| 帮记里的证件安全吗？ | 敏感信息查看需生物识别验证，数据本地处理（TEE） |
| 数据能删吗？ | 可在设置与对应功能内管理；具体路径以《隐私声明》与实机为准 |
| 企业场景怎么用更稳？ | 本地 AI + 基本模式 + 关闭个性化，并遵循企业合规要求 |
