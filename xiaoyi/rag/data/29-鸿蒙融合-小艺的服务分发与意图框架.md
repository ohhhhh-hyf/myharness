# 小艺的服务分发与意图框架（开发者视角）

> 应用的业务能力如何"被小艺找到并调用"？答案是 **Intents Kit（意图框架）**：
> 把功能声明成"意图"，系统再分发到小艺对话、小艺搜索、小艺建议等系统入口。

## 一、Intents Kit 是什么

- **定位**：HarmonyOS 级的**意图标准体系**，将应用/元服务业务功能智能分发到系统入口；
- **分发入口**：**小艺对话、小艺搜索、小艺建议**（以及系统导航条、多模态交互等）；
- **四类智慧分发特性**：

| 特性 | 含义 |
| --- | --- |
| 习惯推荐 | 按用户习惯在合适时机推荐 |
| 事件推荐 | 由事件触发（日程、状态变化等） |
| 技能调用-语音 | 用户通过语音触发应用功能 |
| 本地搜索 | 在小艺搜索里直接搜到应用内功能并直达页面 |

- **两种运行方式**：
  - **意图调用**：系统主动调用应用功能（前台/后台）；
  - **意图共享**：应用主动向系统共享意图（供分发）。
- **设备与地域**：仅适用 Phone / Tablet / PC 2in1；仅支持中国境内。

## 二、意图的接入方式（两条主路）

### 路线 A：声明式意图（标准协议）

1. 在应用工程中声明意图（如功能搜索意图 `JumpFunctionPage`，端侧前台意图调用）；
2. 配置 `insight_intent.json` 意图声明，实现 `InsightIntentExecutor`；
3. 功能搜索方案自 **5.1.0(18)** 起支持：用户可在小艺搜索直接搜到应用内功能并直达。

### 路线 B：小艺开放平台（意图集 / 插件）

- 注册路径：华为开发者联盟 > 管理中心 > 生态服务 > **智慧服务 > 小艺开放平台 > 意图框架**；
- 在「**意图集（插件）**」中配置端侧/云侧意图、API 接口、认证方式等；
- **意图框架兼容 MCP**：可在「意图集（插件）」页面选择 **MCP 协议**创建意图集；
- **自定义意图**：从 **6.0.0(20)** 起支持装饰器开发意图（Link 跳转、Page、函数等）；
- 审核周期一般 **3–5 个工作日**。

## 三、与小艺智能体的关系

- 智能体（Agent）与意图/Skill 是不同粒度：智能体是独立服务主体，Skill/意图是可被调用的能力；
- 小艺开放平台支持四种 AI 生态形态：**云侧 Agent、端侧 Agent、云侧 Skill、端侧 Skill**；
- 智能体上架后通过**系统级入口**（导航条、小艺搜索、小艺建议）与广场分发；
- 截至 2026-06：平台累计 **2000+** 智能体、**500+** 伙伴精选 Skills、**2000+** 标准意图（含自定义）。

## 四、端到端接入流程（概览）

```text
1. DevEco Studio 开发：声明意图 / 实现执行器（insight_intent.json + Executor）
2. 申请调试白名单（联系 hagservice@huawei.com）并真机验证
3. AGC 上架应用
4. 小艺开放平台注册意图（意图集/插件，可走 MCP 协议）
5. 审核（约 3–5 个工作日）→ 系统入口生效
```

## 五、常见问题

| 问题 | 解答 |
| --- | --- |
| 只想让应用功能被搜到，最小改动是什么？ | 接入功能搜索意图（5.1.0(18)+），声明 `JumpFunctionPage` 并实现执行器 |
| 能用 MCP 吗？ | 可以：意图集（插件）支持 MCP 协议创建 |
| 意图和 Skill 谁先谁后？ | 意图框架是分发基础设施，Skill 是能力封装；两者可组合（Skill 化） |
| 模拟器能调吗？ | 落地与调试以真机为主（智能体侧同样要求真机、境内、联网） |
| 审核多久？ | 意图注册审核一般 3–5 个工作日 |
