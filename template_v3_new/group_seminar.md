# [讨论议题与背景]
[一段话概括讨论主题、成员构成及核心探讨问题（一段写完，约 250–400 字）：① 成员构成（人数、身份或编号，照原文）② **为什么现在讨论这个**（由头或前情，原文有才写）③ 谈到的议题范围（把议题名列出来）④ **讨论的整体倾向或是否有结论**（分享型写明「以分享观点为主，未形成统一结论」；**一致与分歧的明细归 [共识形成]，本栏不复述**）⑤ 原文有关键数字、时间或专名时选 1–3 个作锚点，没有则不强求 ⑥ **讨论怎么推进的**（按议题逐块推进还是漫谈发散，一两句）；**不展开各方发言明细（那是 [发言要点] 的事）**；不留空]

# [发言要点]
[两种组织方式，按原文实际选一种，不要硬套：① **成员发言集中**时按成员分节——每位成员一行 `## 成员称呼`（有姓名写姓名；无姓名按原文编号或角色，同一人在全篇只用一个称呼），其下 `- ` 一条一行写他的主张与论据；② **议题分散/漫谈型**时按议题分节——每个议题一行 `## 议题名`，其下 `- **成员称呼**：主张与依据`。**交锋要写实：谁主张什么、谁反对、反对的理由或依据是什么；同一议题下的多条交锋各占一条**（只有同一次发言的碎片才合并）；每条 30–100 字、一条一件事，信息多就拆条或加缩进子条 `  - `；**原文提到的具体数字、次数、案例、时间要落进对应条目，不要只写主张**]

# [共识形成]
[写清两侧（约 150–300 字）：① 一致意见或产出（有则写，关键产出**加粗**）② **没有统一意见时写本场达成的倾向性认识与主要分歧点**——写清谁与谁不一致、分歧在哪（不要只写「无」）③ 原文给出的关键数字或结论口径照原文写]

# [待探讨问题与后续]
[先写需进一步探讨、核实、未定论的问题：原文里的疑问、未达成一致的分歧、被搁置的话题，一条一个，用「未确认：…」「待核实：…」「未定论：…」这类句式起头；原文若有分工或后续约定（谁去查什么、下次聊什么、会后做什么）就接着写，**没有就不写这一段，不要编造分工**；原文提到但没聊透或明确说下次继续的话题都算，确实两者都没有则写「未提及」（不写说明句）]
