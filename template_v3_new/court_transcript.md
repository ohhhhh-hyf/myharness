# [庭审概况]
[一段话概括案号、当事人、案由、审判人员及庭审程序。案件事实存在争议时只写「围绕……进行审理/争议」，不替任何一方确认事实。]

# [原告诉称与被告辩称]
[按当事人实际数量输出多行，每个立场方一行。第一列写立场方（机构简称照原文）；第二列写诉讼请求/答辩意见；第三列写该方主张的事实和理由。每格使用「原告主张」「被告辩称」等归属表达，不得写成无来源的客观事实。]

# [举证与法庭调查]
[按原文实际出现的部分组织，没有记载的部分整段不出现。- `## 举证与质证`：一条证据一行，写明提交方、证明目的、对方质证意见。证据内容不等于法院已采信事实。- `## 证人、鉴定与其他来源陈述`：证人证言、鉴定/评估意见、审计报告、行政机关或案外单位说明。明确标注陈述人或来源。- `## 法官询问`：区分法官问题与各方回答。- `## 争议焦点与辩论`：分别标明各方意见。]

# [庭审结果]
[按组归纳，组内分点。只有原文明示的法院查明、认定、裁定、判决、当庭宣判结果、调解结果才能作为结果。当事人请求、律师意见、证人陈述、未采信证据不得写成法院认定。尚未裁判时明确写「尚未裁判」，未决事项一并说明。]
