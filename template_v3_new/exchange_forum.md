# [沟通背景与目的]
[一段话概括参与方、沟通主题与目的、整体结果或基调（一段写完，约 250–400 字）：① 参与方（机构/身份照原文）② 为什么沟通、要解决什么 ③ 整体结果或基调（原文没有明确结果就写「未提及」）；**不展开发言明细与数字清单（那是 [核心信息与数据] / [各方立场与诉求] 的事）**；**本栏不出现成串的统计数字与专名清单**——人数、经费、奖项、平台名、学科名、年份区间都归 [核心信息与数据]（反例：不要写「本科生 1545 人、教师 302 人、近 5 年科研经费 3–4 亿元、获国家科技奖励 11 项」）；**写完数一下：出现 3 个以上数字就说明串栏了**——删掉数字与专名清单，只留参与方、沟通目的、整体结果三项；**超过 400 字不合格**：删到 400 字以内，只能删数字、专名与介绍性事实]

# [核心信息与数据]
[承载一方宣贯或介绍的事实要点：按主题分组（每组一行 `## 主题名`，主题取原文说法，如单位概况 / 业务与平台 / 师资与成果 / 政策口径 / 人才培养），其下 `- ` 一条一行（`- **要点**：内容`，每条 30–120 字），**数字、年份、比例、专名、政策名照原文写全**；条数由原文决定——原文提到几个事实就写几条，不要压成长段、也不要只挑几条；本栏只写事实要点，各方诉求与回应归 [各方立场与诉求]；原文没有这类介绍性内容就写「未提及」]

# [各方立场与诉求]
[只写多方互动：谁提出或关注什么、对方如何回应、分歧在哪；按参与方写（`- **参与方**：诉求或回应`，一条一行、不要写成整段、不要合并成「双方一致认为」）；事实与数字清单归 [核心信息与数据]，本栏不复述；原文没有多方立场或诉求就写「未提及」]

# [达成共识]
[只写已明确达成或确认的结论、口径与承诺（关键承诺需**加粗**，关键承诺的原话用 > 引用、逐字保留，整栏最多引 3–5 句）；**待定、计划、尚未确定的事项一律归 [待协调事项与后续]，不要写成本栏的共识**；已在其它栏写过的内容不复述；原文没有明确共识就写「未提及」（有讨论但无结论时写「未达成明确共识」）]

# [待协调事项与后续]
[**分两组写，有内容才写该组**：① `## 待协调事项`——未定、待确认、需对接或需支持的事，一条一行 `- **事项**：对接人 / 负责人 / 预计时间`（缺的项不写，不要逐项标「待定」）；② `## 后续安排与参与方式`——联系方式、群号、链接、重要时间节点、报名或参与渠道、福利与优惠信息等读者接下来要做什么（照原文写全）；两组都没有内容就写「未提及」]
