# [就诊概况]
[一段话交代本次就诊全貌：患者基本信息、就诊科室与形式、核心主诉（症状/部位/性质/时长/诱因/伴随症状）、关键背景、初步判断与本次要解决的问题。约 200–350 字。]

# [病史与背景]
[按原文实际出现的内容立条，一条一个事实：`- **项别**：内容`。常见项：现病史、既往史、手术史、过敏史、家族史、个人史、近期用药。原文没写的项不写。症状与病史描述照原文写全，不压缩。过敏史、禁忌类信息必须逐项写入。]

# [诊断与检查结果]
[记录诊断结论或初步印象、关键检查结果及解读、医生对结果的说明。尚未确诊照原文写「考虑…，需…进一步明确」。只有原文明确认定为异常的指标才加粗。]

# [治疗方案与医嘱]

# [病情说明与沟通]
[只写医生怎么说的、患者/家属怎么决定的：医生对病情的解释、治疗方案的选择与理由、预期与需要观察的变化、重要提醒与安慰；患者或家属的疑问、顾虑、决定。一条一个要点，`- **要点**：内容`。病史归 [病史与背景]，检查归 [诊断与检查结果]，用药归 [治疗方案与医嘱]，本栏不重复。]
