# [发布会概况]
[一段话概括发布会主题、发布单位与整体基调。约 300–400 字，包含：- 时间地点、主办/发布单位、发言人身份、到会媒体（原文有才写）；- 发布的板块或讲话的分点主张；- 一句话定性或结论；- 1–3 个关键数字锚点（只报数字，不铺开）；- 问答环节涉及的议题与后续安排（原文有才写）。逐项信息归 [核心信息]，官方立场归 [官方表态]，问答归 [Q&A环节]，本栏不复述。]

# [核心信息]
[提炼官方发布的关键事实、核心数据及政策举措，分两层：- 一级：按发布板块或主题分组，`## 板块名`（组名照原文；原文只有序数时按内容自拟短语）；- 二级：组内 `- **要点**：内容` 一条一行，一条一个主题。同一文件、同一板块、同一口径的多项指标合并成一条，并列表述用顿号或缩进子条 `  - ` 拆开。每条交代依据（文件/政策/规划名）、口径与范围（同比/环比/基数、适用对象与时限）、时间表（发布与生效时间分开写）。数字与结论必须与原文对得上。第三方来源的信息在条内标出来源。立场与主张归 [官方表态]，同一事实不两栏都写。]

# [官方表态]
[只写发言人主动表态（政策宣示类）；与提问对应的回应归 [Q&A环节]；[核心信息] 写过的政策举措不重写。按 机构/职务＋议题 分组，每组 `## 机构或职务｜议题`；单一发言人时组名只写议题。每组最多 3–4 条，每条 40–120 字；同一议题下多个数字合并进一条；观点类只写结论 + 关键依据。保留限定语与程度（力争/有望/原则上/除…外），不省成确定表述；政策、法律、会议名称照原文写全。`>` 只引原文连续原话，逐字照抄；概括句或拼接句不算引语。第三方表态另起条目标来源，不与官方口径混写。整栏约 400–800 字，超出时保留带结论与关键数字的表态，删除重复论证与铺陈。]

# [Q&A环节]
[一问一答＝一条记录，按提问顺序逐条展示。格式：**记者（媒体名 姓名）**：…**答方姓名**：…条与条之间空一行。称呼规则：提问方写「媒体名＋姓名/记者」；答方能确定姓名就写姓名，全篇统一；确实没有姓名才写「问」「答」。每轮称呼加粗；开头已是称呼，不再写「主持人提问」这类重复说明。答话可压缩：超过约 400 字压到 400 字以内（删例子、铺垫与重复强调，保留结论、数字、条件与时限），仍单段连着写。原文没有正式问答就写「未提及」。]
