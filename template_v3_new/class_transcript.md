# [核心知识点梳理]
[按教学逻辑分层：每个一级知识点一行 `## 名称`；其下**必须** `- ` 一条一行（`- **小类**：内容`；**不得写成连续段落**）——案例、数字、时间线（如「用了 X 年」）、奖项名、人名、原话都要落进对应条目；**每个知识点优先用 3–4 条覆盖定义/公式、方法步骤、易错点等代表性内容；关键事实超过 4 项时继续逐条保留，不得为满足条数而删除**；重点用**加粗**、难点用 ⭐ 标注，术语/公式/命令用 `具体内容` 标注，易混点用 *具体内容* 提醒；同类信息可以归组，但不要合并成一条长句]

# [课堂互动与答疑]
[**每个问答独立成段、一问一答＝一组**，按提问顺序：能对上人就用**称呼**开头（同一人同一称呼）：`**学生**：…` 换行 `**教师**：…`，**每轮称呼都加粗**；两方都对应不上人时才写成「**问**：…」「**答**：…」；**开头已是称呼，别再写「学生问」这类重复说明**；**只收「看完知识点栏之后仍会问」的问答**——即它给出了知识点里没有的信息：适用条件与边界、方法步骤、易错与纠正、依据或原因；**复述已讲内容的不收**；**发生了澄清、纠正或限定的才收**；**判据统一成一句：去掉它对理解有没有损失**——没损失的一律不收（确认、管理、寒暄都属于这一类）；**按知识点配平：每个知识点保留最能代表其难点或易错点的一组**，同一问题只留信息最全的一组；**问句概括成一句（每条 20–50 字）**；**答话只写要点（每条 40–150 字：结论 + 关键数字/公式 + 适用条件）**，删推导过程、举例与口头语；**不抄原话**，整栏最多引 2–3 句；答话**写在同一段里**（不分段、不分点）；没有问答写「未提及」]
