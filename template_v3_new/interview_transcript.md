# [访谈概述]
[一段话概括采访主题、受访者身份与背景、核心采访目的及内容概述（一段写完，约 250–400 字）：① 受访者身份与背景（职业/机构/代表作照原文）② 采访主题与目的 ③ 访谈主线与覆盖的话题（把议题名列出来）④ **受访者最核心的观点与结论 1–3 条**（每条一句话点题，可带原文的关键数字或事例作依据）⑤ 原文有关键数字、时间或专名时选 1–3 个作锚点（作品名、年份、地点），没有则不强求 ⑥ **这场访谈的看点**（受访者强调的独家经历、亲历细节，或受访者自己指出的与流俗看法不同之处——**以受访者原话为限，不做外部比较**）；**不展开受访者的论据与细节（那是 [访谈详细记录] 的事）**；原文没有的项写「未提及」]

# [访谈详细记录]
[两级结构：每个议题一行 `## 议题名`，其下一条一行记录受访者的观点与事实陈述，数字、时间、地点、人名照原文）；**一个议题下有多个观点或事实就各自成条，不要压成一条；同一个观点讲到的细节、例子、时间线也落进该条**；受访者陈述的事实与他个人的看法、推测分开写，看法标明「受访者认为」；不要自建表格]

# [关键引语与金句]
[逐字摘录受访者原话中最能代表其立场、信息量最大的句子，**最多 8 句，有几句写几句**（不硬凑；**金句行用 `>` 引用并加引号**（`> “……”`）、逐字不改字、不合并）；**每条金句下一行背景，格式固定：金句行 `> “……”`、背景行 `- 背景：……`**——背景一句话即可，这句话在什么情形下说的：回应什么问题/谈到什么话题、针对谁或什么事（原文没线索就写 `- 背景：未提及`，不编）]
