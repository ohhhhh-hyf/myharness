# 对话记录

# [对话概况]
[一段话概括（一段写完，约 250–400 字）：① 参与方与场合关系（有姓名写姓名；没有姓名时只写原文明示的角色或关系；原文没有身份线索就不补关系、不作推断）② **为什么聊起这个话题、话题走向**（一两句：谁起的头、怎么转到下一块）③ 主要话题（把话题名列出来）④ **倾向与差异对照**：多数人怎么看、谁与谁不同、为什么（2–3 句；分享漫谈型写明「以分享为主，未形成明确结论」）⑤ 原文有值得记的数字或具体事例时选 1–3 个作锚点，没有则不强求；**不逐条复述各方发言（明细归 [交流内容]，原话归 [关键原话]）**；不留空]

# [交流内容]
[按话题分条：每条写成 `- **话题**：谁提出/主张什么/对方如何回应/有无定论`；同一次发言的碎片合并成一条，不一句一条；**同一话题下每位发言人的说法各占一条缩进子条 `  - `，不要把多位发言人塞进同一条**；人名、地点、物品名、约定事项、数字用 `具体内容` 标注；**原文给的具体细节（数字、次数、例子、时间、地点、约定）都要落进对应条目，不要只写主张**；每条 30–100 字；本栏不夹引用——原话统一放 [关键原话]]

# [关键原话]
[逐字摘录最能代表各方立场、信息量最大的原话，**最多 8 句，有几句写几句**（不硬凑；**金句行用 `>` 引用并加引号**（`> “……”`），不改字、不合并）；**每条原话下一行背景，格式固定：金句行 `> “……”`、背景行 `- 背景：……`**——背景一句话即可，这句话在什么情形下说的：聊到哪个话题、谁对谁说的、针对什么事（原文没线索就写 `- 背景：未提及`，不编）；**同样的意思，原文有原话就用原话**，不要改成转述；原文确实没有可摘的原话就写「未提及」]

# [共识与分歧]
[写**由事实得出的判断**，写明各方立场与理由（约 150–300 字）：① 一致的地方是什么、为什么大家都认同 ② 不一致的地方在哪、**分歧的性质**（必要 vs 安心、审美差异、习惯差异）③ 分享漫谈型没有明确共识或分歧时，写**本场的倾向与依据**（如「多数人认为手机必带，分歧只在『必要』与『安心』」），不要写「未提及」，也不要硬凑结论；**不要复述各人分别带什么、认为什么（事实明细归 [交流内容]）**；关键共识可用 **加粗**，敏感或仍待确认的判断可用 *具体内容* 标注]

# [延伸话题与后续]
[先写本场被提起但没聊完、或明确说"下次/改天再聊"的话题（一条一个，照原文说法，不要自拟话题名）；原文若有承诺、约定或后续行动（谁去做什么、什么时候、约在哪里）就接着写，**没有就不写这一段，不要编造**；确实两者都没有则写「未提及」（不写说明句）]
