# [研讨背景与议题]
[上半段一段话交代研讨背景：主题、参与方（人数/机构/方向照原文）、为什么开这场研讨；下半段按议题逐条列出（`- **议题名**：要解决的核心痛点 / 待解问题 / 为什么重要`），议题名取原文说法，一条一个议题，宁多不漏；人员与数字照原文]

# [核心观点]
[按议题维度梳理：不同视角的观点、提出的创新思路、数据或案例支撑。对立观点分别标注提出方（人名或角色）]

# [达成共识与解决方案]
[有共识就写共识：谁与谁一致、依据是什么；**未形成统一结论时直写「未形成统一结论」，再写本场的倾向性认识与主流意见**（不要用观点罗列充当共识）；解决方案写成可落地条目：对象 + 做法 + 依据/前提，原文没有就写「未提及」（不写说明句）；关键结论用**加粗**]

# [未决分歧与后续探索]
[每条写清：分歧点是什么 + 双方各自主张（标注提出方）+ 需要验证什么 / 谁跟进（原文有才写）；整条确实无信息就**不写该条**（不要逐条标「未明确」）；整栏都没有内容时才用一次「未明确」]
