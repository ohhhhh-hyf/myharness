# [问答概况]
[用一段话概括问答场合的基本信息，包括时间、地点、发言人身份、参与媒体或机构、讨论的核心议题]

# [核心提问与回应]
[**一条问答独立成段，一问一答＝一条记录**，按原文提问顺序**逐条编号**：`**1. 记者（人民日报 张宇）**：…` 换行 `**陈立**：…`（答方写姓名；确实没有姓名才用「答」），条与条之间空一行；提问方写「媒体名＋姓名/记者」（原文任何位置出现过姓名就必须用，**不得用「记者」「发言人」顶替已知姓名**）；**回应方能确定姓名就写姓名**（全篇统一用同一个称呼；只有确实没有姓名时才写「**答**」）；**称呼只写 姓名 或 媒体名＋姓名/记者——机构只能跟在人名/媒体名后，不得单独充当身份**；**两方都对应不上人时才写成**「**问**：…」「**答**：…」；**每轮称呼都加粗**；**开头已是称呼，不要再写「记者提问」这类重复说明**；**答话可压缩、不必逐句照抄**：超过约 400 字压到 400 字以内（删例子、铺垫与重复强调，保留结论、数字、条件与时限），仍**单段**连着写（不分段、不分点）；原文没有正式问答就写「未提及」（不要硬凑问答）]

# [媒体关注焦点]
[写媒体重复追问或重点追问的问题（追问顺序、重复次数按原文）+ 官方回应的要点；不做传播效果或社会影响的推断]

# [信息澄清与表态]
[提炼发言人对热点、争议或敏感问题的澄清说明与关键表态，重点内容**加粗**突出；与「核心提问与回应」重复的内容不在这里重写]
