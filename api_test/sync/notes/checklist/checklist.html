核心★★★★★ Definition 1 (μ空间分割)

考法预判. 可能以简答题或论述题形式考查μ空间的分割方法，以及宏观分布与微观态的关系。注意区分不同分割方式对微观态计数的影响。 [2][3]

必须先会.

  • μ空间是单个粒子的位置和动量构成的相空间，将μ空间分割成若干小体积元Δω。
  • 宏观分布由各体积元内的粒子数{n_i}描述，微观态则具体指定每个粒子处于哪个体积元。
  • 一个宏观分布对应的微观态数W = N! / ∏ n_i!（经典统计，粒子可分辨时）。
  • 最概然分布是使W取极大值的分布，对应平衡态。

知识点讲解. μ空间分割是统计物理的基础。将单个粒子的位置和动量空间划分为小格，每个格对应一个可能的微观状态。宏观分布只给出每个格中的粒子数，而微观态则具体到每个粒子。分割的精细程度影响微观态计数，但宏观物理量在热力学极限下与分割方式无关。考试中可能要求计算给定宏观分布的微观态数，或说明最概然分布的意义。笔记中应补充不同分割方式（如等体积元）对结果的影响。μ空间分割是目录里已有的知识点，类型是concept。先把必须会的条目钉死：μ空间的分割方法、宏观分布与微观态的关系。做题时先判断本题是不是在用它，再按方法步骤走，最后回代检查适用条件。 [1][2][3]

方法步骤. [1]

  1. 用自己的话复述μ空间分割的定义或结论，并写出一条限制条件
  2. 按「先看条件再下结论」的流程逐步核验
  3. 用一个正例确认能用，再用一个反例钉住边界
  4. 若要写证明，按「构造 → 验证条件 → 下结论」的顺序落笔

易错提醒.

  • 注意粒子是否可分辨，可分辨时用N! / ∏ n_i!，不可分辨时需除以N!。
  • 分割体积元必须足够小，但又不小于量子力学不确定关系限制。

核心★★★★★ Definition 2 (一维束缚态)

考法预判. 可能以计算题或证明题形式考查一维束缚态的求解，特别是势函数不连续时的处理。注意分离变量法的应用和束缚态条件的判断。 [1][2]

必须先会.

  • 束缚态是能量E小于无穷远处势能V(∞)的态，波函数在无穷远处趋于零。
  • 一维定态薛定谔方程可用分离变量法求解，波函数ψ(x)满足ψ'' + (2m/ħ²)(E-V)ψ = 0。
  • 定理1：若势函数V(x)在某点不连续，则波函数ψ和ψ'在该点连续（当势跳跃有限时）。
