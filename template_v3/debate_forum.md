# [辩论内容概述]
[一段话交代：辩题、正反双方立场（各一句话概括）、辩论整体走向（交锋的核心议题；**转折或占优只在原文明示时写**——评委/主持人点评、辩手自陈，不自判）；**不展开具体论据与交锋细节（那是 [核心论点] / [环节交锋] 的事）**；一段写完，约 250–400 字]

# [核心论点]
[正文交代辩题、正反方立场与整体格局（一两句即可）；正反方的立论框架、核心论点与支撑论据**只写进下表**——**按原文出现顺序排列（同一环节内正反交替），不要把一方的论点归堆写完再写另一方**；**行数＝论点数**（原文有几个论点就写几行，每方通常 2–4 行，**不要一方一行、也不要求两方行数对称**）；一个论点下的多个论据用 `；` 分隔列全；正文不复述表内内容]

# [争议焦点]
[按**议题**归纳双方真正的分歧（不是按环节复述交锋）：每条一个焦点，`- **焦点**：争的是什么；正方：…；反方：…`（一方没有对应主张时只写有的那侧）；**3–5 条，原文出现过的焦点都要有**——论点表里每对相反的主张就是一个焦点，**看完通篇回头归纳**，不要与 [核心论点] 的表述逐字重复；**只归纳双方的立场与依据，不做输赢、高下或"谁更有道理"的判断**（原文明示占优才写，且写在 [结辩与评委点评]）；原文没有形成观点对立的就写「未提及」]

# [环节交锋]
[按原文实际出现的环节分组（如开篇立论 / 质询 / 自由辩论 / 小节总结，环节名取原文的说法）：每个环节一行 `## 环节名`，其下 `- ` 一条一个争议点（先写一方进攻、紧接写对方回应，写清谁攻谁守），**每个环节 2–5 个交锋点**（原文有几个写几个，不要把一轮交锋压成一条）；原文没有环节线索就直接按交锋顺序分条，不要硬分组；**原文没有区分说话人时按立场归入正方/反方，判不准就写「一方」**；**每个交锋点尽量带 1 句原文引用**（`> ` 逐字不改写），归不到人时只引原话、不署名]

# [结辩与评委点评]
[**分三条写**：`- **正方结辩**：…`、`- **反方结辩**：…`、`- **评委点评**：…`（原文没有的条不写）；每条写清核心升华点与关键判断（数字、环节、名次照原文），**每条 60–150 字**；**原文明示获胜方时才标注**（评委宣布、赛制规则或双方确认），未明示不写；评委的总结性判断或点题句用 *具体内容* 突出]
