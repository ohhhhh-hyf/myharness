# [发布会概况]
[一段话概括发布会主题、发布单位与整体基调（一段写完，约 300–400 字）：① **时间地点与主办/参与**（发布时间、地点、主办与发布单位、发言人身份、到会媒体，照原文；没有的不编）② 围绕哪几块——**有发布板块就列板块名；单一讲话没有板块时列讲话的分点主张名**（如「围绕四点看法：平等相待 / 国际法治 / 多边主义 / 开放共赢」）③ 一句话定性或结论 ④ **原文有的关键数字锚点 1–3 个**（届次、年份、人数、比例——只报数字、不铺开数据）⑤ **问答环节涉及的议题与会议后续安排**（原文有才写）；逐项信息与数据照原文写进 [核心信息]、官方立场归 [官方表态]、问答对话归 [Q&A环节]，本栏不复述]

# [核心信息]
[提炼官方发布的关键事实、核心数据及政策举措，**分两层写**：① 先按发布板块或主题分组——每组一行 `## 板块名`（组名照原文；原文只有「第一项/第二项」这类序数时按内容自拟短语），**每组 3–5 条**；② 组内 `- **要点**：内容` 一条一行，**一条一个主题**——同一文件、同一板块、同一口径的多项指标或举措**合并成一条**，并列表述用顿号或缩进子条 `  - ` 拆开，不要拆成一指标一条、一举措一条；**覆盖度以板块/主题为单位保证**：原文的每个板块、每项政策文件、每组数据都要有落点，数字、时间表、适用范围与对象、执行方式不落项；同一指标的多组取值（基线与现状、目标与完成）写成一条对照，不要只留一侧；每条交代**依据**（文件、政策或规划名）、**口径与范围**（同比/环比/基数、适用对象与时限）、**时间表**（发布时间与生效/执行时间分开写）——原文没有的不编；**数字与结论必须与原文对得上，不换算、不估算、不自行加总，不用「据悉/有关方面」模糊来源**；**本栏不逐条写人名**（不写「某某表示/强调」这类前缀）；第三方或非官方来源的信息才在条内标出来源；**数据与政策举措进本栏，立场与主张归 [官方表态]，同一事实不要两栏都写**；关键数据加粗，文件名、政策名、日期、机构名用 `具体内容` 标注]

# [官方表态]
[只写发言人**主动**表态（政策宣示类；与提问一一对应的回应归「Q&A环节」，[核心信息] 写过的政策举措不在这里重写——**同一内容不要两栏都写**），**整栏约 400–800 字**：**按 机构/职务＋议题 分组逐条还原**（每组一行 `## 机构或职务｜议题`；**单一发言人时组名只写议题**，如 `## 关于多极化世界`；一次表态含多个承诺或条件时分别列条，不要压成一句）；**每组最多 3–4 条、每条 40–120 字**，**同一议题下的多个数字合并进一条**（不逐数字列条），观点类表态只写"结论 + 关键依据"、不写推演过程；超出 800 字时按支撑力取舍：保留带结论与关键数字的表态，删除重复论证与铺陈；**不写身份行**（发言人身份见 [发布会概况]；多位发言人由每组标题的机构或职务承担，单一发言人不另标）——**不重复栏名、不把会议背景或议程写成导语**（背景归 [发布会概况]）；**条目不逐条写人名、不写「某某强调/指出」这类前缀**；**挖到四层**：主张（含呼吁与要求）、针对什么、条件与前提、承诺或边界（不做什么）；**照原文保留限定语与程度**（力争/有望/原则上/除…外不得省成确定表述），引用的政策、法律、会议名称照原文写全；**`>` 只引原文连续原话、逐字照抄**（概括句或拼接句不算引语；长引语改为照原文措辞的要点）；记者/嘉宾/机构等**第三方表态另起条目标来源**，不与官方口径混写]

# [Q&A环节]
[**一条问答独立成段，一问一答＝一条记录**，按提问顺序**逐条编号**：`**1. 记者（人民日报 张宇）**：…` 换行 `**陈立**：…`（答方写姓名；确实没有姓名才用「答」），条与条之间空一行；提问方写「媒体名＋姓名/记者」（原文任何位置出现过姓名就必须用，**不得用「主持人」「发言人」顶替已知姓名**）；**回应方能确定姓名就写姓名**（全篇统一用同一个称呼；只有确实没有姓名时才写「**答**」）；**称呼只写 姓名 或 媒体名＋姓名/记者——机构只能跟在人名/媒体名后，不得单独充当身份**（写「主持人（某会议）」不合规：要么写原文里的姓名，要么就写「主持人」）；**两方都对应不上人时才写成**「**问**：…」「**答**：…」；**每轮称呼都加粗**；**开头已是称呼，不要再写「主持人提问」这类重复说明**；**答话可压缩、不必逐句照抄**：超过约 400 字压到 400 字以内（删例子、铺垫与重复强调，保留结论、数字、条件与时限），仍**单段**连着写（不分段、不分点）；原文没有正式问答就写「未提及」（不要硬凑问答）]
