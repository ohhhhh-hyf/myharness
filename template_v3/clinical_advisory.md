# [就诊概况]
[一段话交代本次就诊全貌（一段写完，约 200–350 字）：① 患者基本信息（姓名、性别、年龄、职业照原文）② 就诊科室、时间与形式（初诊 / 复诊 / 家属代述 / 线上，原文有才写）③ **核心主诉照原文写全**（症状、部位、性质、时长、诱因、伴随症状——不要只写一句「上腹痛」）④ 关键背景一笔带过（既往病史、过敏、近期用药，一两句；明细归 [病史与背景]）⑤ 初步判断与本次就诊要解决的问题（未确诊照原文写「考虑…，需…进一步明确」）；病史与用药细节归 [病史与背景] / [治疗方案与医嘱]，不在这里重复；整栏都没有内容才写「未明确」]

# [病史与背景]
[客观记录与本次就诊相关的背景（约 250–450 字）：**按原文实际出现的内容立条**——常见项：现病史要点（起病时间、诱因、既往发作规律、伴随症状、演变过程）、既往史与手术史、过敏史（药物/食物）、家族史、个人史（职业、吸烟、饮酒、作息）、近期用药与自备药；**原文说到哪几项就写哪几项，不要为凑清单把没有的项写成「未提及」**；一条一个事实（`- **项别**：内容`），原文没写的项不写；**症状与病史的描述本身就是核心事实**——照原文写全（部位、性质、时长、诱因、发作与缓解、伴随症状、既往发作与处理），**不得当成「过程铺陈」压缩成一句**；**过敏史、禁忌类信息原文出现就必须逐项写入，不得省略**；整栏都没有内容才写「未明确」]

# [诊断与检查结果]
[记录原文给出的诊断结论或初步印象（**尚未确诊就照原文写「考虑…，需…进一步明确」，不把推测写成确诊**）、关键检查/检验结果及解读、以及医生对结果的说明（如某项检查没发现问题而影像有问题、为什么要复查）（约 150–300 字）；**只有医生或原文明确认定为异常、偏高、偏低或需关注的指标才加粗**，不得依据医学常识、参考范围或模型判断自行认定异常；未被原文定性的指标按普通文本记录。检查名、指标缩写、药品名可用 `具体内容` 标注；整栏都没有内容才写「未明确」]

# [治疗方案与医嘱]
[医嘱清单（约 200–400 字）：**按原文实际给出的类别立条**（检查安排、用药、生活方式、复诊与陪同等，**有哪几类写哪几类，没有的类别不立条、不写缺省**），**每条都是 `- ` 分点行**（`- **类别**：内容`）；同类下有多条时用缩进子条 `  - `；不要用连续多行独占一行的 `**类别**：` 段落代替分点；药品明细**只写进下表**（**原文出现过的药名一行一药**；用法用量、注意事项原文没写的单元格写 `—`；**原文没有任何药品信息时整表只写一行「未提及」**），正文不重复药品名称与用法用量；需要解释的用药说明（如为何换药/停药）写进对应条目；重点禁忌、高风险提醒用 **具体内容** 强调；整栏都没有内容才写「未明确」]

# [病情说明与沟通]
[只写**医生怎么说的、患者/家属怎么决定的**（约 150–300 字）：医生对病情与检查结果的解释（含通俗说明与比喻）、对治疗方案的选择与理由（为什么这样治、为什么不那样治、什么情况下才考虑某种处理）、预期与需要观察的变化、重要提醒与安慰；患者或家属提出的疑问、顾虑，以及他们的决定（同意 / 暂缓 / 由患者自行决定）；一条一个要点、`- ` 一条一行（`- **要点**：内容`）；**医生问诊时采集的病史归 [病史与背景]，检查与诊断事实归 [诊断与检查结果]，用药与安排归 [治疗方案与医嘱]，本栏只写"说明与沟通本身"、不重复**；原文没有解释或沟通内容就写「未明确」]

# [复诊与预警信号]
[**原文给了复诊/随访安排才写复诊时间**（复诊、随访、复查项目与时间照原文）；需立即就医的预警症状用 ⚠️ 醒目标注，**原文提到的预警症状必须逐项写入**；需要观察的变化（监测什么、什么情况要提前联系）也写进本栏（约 80–200 字）；两项都没有就写「未明确」（不要留空）]
